## 1. 总体架构

### 1.1 分层

| 层 | 内容 | 精度行为 |
|---|---|---|
| L0 整数层（已有） | MULX/ADX 汇编、u52/IFMA、pq16 FFT、p48 NTT、Newton 服务、二分级数引擎、radix | 已有契约不变；浮点需要的新能力补在这里（§6.5 列出清单） |
| L1 原始层 `sbn::fp` | `fx`：约化定义域上的定点内核，由生成器产生，误差界是 `constexpr` 常量。`raw`：浮点级函数，负责约化和调度，返回误差（ulp），需要计划时自己从计划缓存取 | 每个函数用一行 `//@` 规格声明输出网格、误差上界、定义域和 n 的范围。没有契约对象 |
| L2 球层（公开，`sbn::ball`） | 中点 + 半径；特殊值；输入半径传播；按半径降精度；调度 | 唯一对外的保证是：球包含真值 |
| L3 正确舍入定精度层 | 推迟 | 用 L1 返回的误差做 Ziv 测试，必要时有自己的小尺寸内核（§4.15） |

L2 的每个函数只调用一次 L1，不在内部串联 L2 运算。这是从 astra 实现得到的最主要的反面教训：它的每个原语有 40–50 ns 的契约开销，一个 64 bit exp 串了约 74 个原语 [实测，`runs/2026-10-08-design-probes/astra_mb.cpp`]。

### 1.2 数据表示

**尾数**：u64 limb，小端，规格化（最高 limb 的最高位为 1），值 = (−1)^s · m · 2^(exp − 64n)，即 |x| ∈ [½, 1)·2^exp。选 u64 而不是 u52，有三个理由：pq16、p48 NTT、Newton 服务和 radix 都直接读 u64；arf 和 nfloat 也用这种形式；u52 只在融合内核内部使用，进入时解码一次，退出时编码一次（§3.2）。

**指数**：int64，有限值满足 |exp| < 2^61。两个指数相加再加上小的调整不会溢出，2^61 以上的值用作哨兵（inf、不定）。指数加偏置后，一次 OR 加一次移位就能同时判断两个操作数是否走快路径。

**半径**：u64，计数单位是中点最低 limb 的 ulp（与 mp_real 相同）。

| 规则 | 内容 |
|---|---|
| 精确值 | rad = 0，跳过所有半径运算。精确值去掉尾部零 limb 后存储，因此短整数和短二进制小数天然走短操作数快路径 |
| 溢出 | rad ≥ 2^64 时丢掉中点的低 limb：rad' = (rad >> 64k) + 2，n' = n − k。中点因此不会携带超过约一个 limb 的噪声，这本身就是"按半径降精度" |
| 宽球 | n = 1 时仍然溢出，说明球已经包含 0：重定中心为 [0 ± (\|m\| + r)]，宽度至多扩大一倍，不需要单独的宽球格式 |
| 不精确值 | 永不去尾零（去尾会使半径按 2^64 放大） |

**实测代价** [实测，`runs/2026-10-08-design-probes/rad.csv`，含间接调用开销]：

- ulp 计数半径在 12 种（运算 × 尺寸 × 模式）组合中有 10 种最便宜，另外 2 种在噪声范围内持平。
- 球乘相对点乘，吞吐开销为 +0.15 至 +0.9 ns；double 半径为 +1.6 至 +2.4 ns；Arb 式 mag 为 +3.3 至 +3.5 ns。
- 加法的半径更新较贵（吞吐 +1.4 ns），生成器要专门优化：预先算好向上取整的移位量，并为 d = 0 和精确输入特化。

**值类型**：

```c
typedef struct sbn3_ball {        /* 32 B；内部入口用 4 个寄存器参数传递 */
    int64_t   exp;                /* n>0: |mid| ∈ [1/2,1)·2^exp；n==0: 半径刻度；≥2^61: 哨兵 */
    uint64_t  rad;                /* 半径 = rad · 2^(exp − 64n)；0 = 精确 */
    uint32_t  n;                  /* 中点 limb 数；0 = 中点为 0 */
    uint32_t  flags;              /* bit0 符号，bit1 堆所有权，bit2.. 容量（limb） */
    uint64_t *d;
} sbn3_ball;
```

- C++ 所有者 `sbn::ball` 由上面的结构体加 4 个内联 limb 组成，共 64 B，正好一条 cache line，≤256 bit 时不需要分配。更大的值走线程级 limb 池（后端是 memory_resource，`src/` 中没有 malloc/new）。
- 容量不够时，`_into` 形式**降低精度继续计算而不是失败**，结果仍是合法的球。
- L1 内部形式：`ff<N>`（定长浮点，放在寄存器或栈上）、`fx<N>`（定点，网格由内核声明）、`fv`/`fr`（动态视图和输出引用）。定长形式只出现在模板内部，从不出现在导出签名里。

**精度语义**（类 Arb，但不完全相同）：

- 精度 p 的意思是以 n = ⌈p/64⌉ 个 limb 计算中点，**不自动加守护 limb**。
- 初等函数在 p = 64n 时交付约 64n − c_f 位，c_f = 1 + ⌈log2 err⌉，err 是 `//@` 规格的 ulp 误差界，由 `specs.py` 自动导出（`//@` 行不单独写 c_f）。上限：S 段 c_f ≤3（松内核 ≤4 ulp），M–X 段 c_f ≤4（级数内核如 exp 总误差 < 8 ulp，§3.5）；fbench 用这个上限而不是规格自报的 c_f 判 acc_bits，误差界松的内核因此过不了门槛。所以 p 恰好等于 64n 时比 Arb 少约 1–4 位，p < 64n 时则多出若干位。
- mp_real 的球运算在 p = 64n 时会多算一个 limb，它的 exp 因此慢 1.17–2.24 倍 [实测，`warm2.csv` 中的 `mp_real.fix` 行]。不加这个 limb，是我们在 S 段的主要优势之一。
- 验收要求：每个 L2 验收点的交付精度都满足 acc_bits ≥ 64n − c_f，fbench 对不满足的点判失败。
- 现在只生成松变体。≤1 ulp 的紧变体留给 L3，或者留给实验 #15 决定之后才设立的"满精度入口"；`config/float-gen.json` 中保留 `err_target` 开关。

|---|---|---|---|---|
| S n=1 | 通用寄存器 | 生成的直线代码；1 limb 除法用硬件 `divq`（约 18 c 延迟 [实测，`small.csv`]） | `mulx` | — |
| S n=2 | 通用寄存器 | 生成的 `unsigned __int128` C++（比现有汇编快：全积 1.33 vs 2.94 ns [实测，`rad.csv`]） | 4 次 mulx | adc |
| S n=3–4 | 通用寄存器 | 生成，完全内联；汇编还是 C++ 由实验 #2 裁决（n=4 两次重复结果不一致） | MULX/ADX | adc |

| M1 9–32 | zmm（≤40 个 u52 数位，即每个值 5 个 zmm） | 生成的整函数内核：约化、级数、重构融合在一起 | 标量 mulhigh 与 u52 mulhigh 的交叉点约在 9–14 limb | IFMA |

| M3 ~231–1024 | L2 数组，表在 L3 | 模板 | pq16 FFT 全积（形状缓存、频谱复用）；cyclic-tail 高半积待实验 | IFMA |
| H / X | 堆上的 scratch | 计划驱动 | pq16 / p48 NTT | IFMA |

### 1.4 调度

- **第一维是 limb 数。** n 不超过定长上限（初等函数 8，实验 #23 若采纳延伸则为 16；乘法类 16）时，用 `switch(n)` 跳转到模板实例；更大的 n 走生成阈值的升序比较链（约 1 ns）。
- **第二维**（每一维一张小的生成表）：
  - 输入有效高度：精确短值走 n×1 路径，H 段走单切片路径（§3.7 第 0 步）；
  - |exp| 类别：三角函数分直接、单 limb 2/π 窗口、Payne–Hanek 窗口三类；
  - 线程数。
- **调用路径上不做规划。** 需要计划的方法（bit-burst、多素数约化、常数生产者、大尺寸 Newton）从进程级计划缓存取计划：
  - 键是（方法, **尺寸类**, 线程数, 约化模式 ∈ {无原子库, 主库（exp/log k_at = 13，三角 32 个高斯原子）, 扩展库（k_at = 48）}, 输入类 ∈ {短精确, 一般}）。bit-burst 计划的切片、N_j、D 树和 1/ΠD_j 都依赖约化模式和输入类，键里少了它们，一种模式下建的计划会被另一种模式误用（项数或切片不够，危及包含性）。尺寸类按 1/16 倍频程划分，计划按类内最大的 n 构建，同一类内的所有 n 共用一个计划。这样密网格扫描和用户逐步加精度重试时都不会每个 n 都构建一次。
  - 命中时只是一次无锁 acquire 读。
  - 缓存容量按字节封顶，满了按 LRU 淘汰。计划是不可变的，用 epoch 回收；淘汰次数要计数。fbench 报告每个点的计划未命中次数，计时循环里出现未命中的点要标记出来。
  - 预算：计划元数据（切片、项数、树形）与计划持有的数据（D 树、频谱、N₀ = 1/ΠD_j；1M bit 时单是 N₀ 就约 290 µs）**合计** ≤ 同精度 warm 调用的 10%（p ≥ 2^18 bit）或 25%（2^16 ≤ p < 2^18 bit），其中元数据另有 ≤50 µs 的绝对上限。这就是章程 §3 第 2 条、§7 和 §2.5 的"只清计划"阈值（≤1.1× / ≤1.25× warm）。现状：astra 的 bit-burst 规划（quote + prepare）在 256–1024 limb 约占总时间的 25–42%（4096 limb 约 12%），64 limb 约 67% [实测，`runs/2026-10-08-design-probes/series/bb3.tsv`、`bb3b.tsv`]。
- 每个算法变体都导出一个内部符号 `sbn3i_fp_<f>_<variant>`，做 A/B 时不需要重新编译，也不需要环境开关。另有两个测量用内部符号：`sbn3i_fp_prewarm(kind, p)`（建 M 段按位表、H 段原子库）和 `sbn3i_fp_plan_clear()`（只清计划缓存）。

### 1.5 SIMD 与 ISA 架构

| 组成 | 位置 | 说明 |
|---|---|---|
| 定长 limb 内核（L0） | `src/core/x86_64/gen/*.hpp` | n ≤ 16 的 mul/sqr/mulhigh/sqrhigh/mulmid/mul_1/addmul_1/sub_n/add_shift/div_1，生成的头文件（内联汇编或 u128 C++，§1.6；不是独立 TU，不需要登记清单）。它们属于整数层，浮点层和整数层（例如修复 `sbn3_mul_basecase` 在 n=7 的断崖）都可以用 |
| IFMA 定长与 u52 内核（L0） | `src/kernels/x86v4ifma/gen/` | 9–16 limb 横向积、u52 高半积/平方、k 项点积、移位加、行减、u52 MAC2；纵向 8 道内核（vmul/vmulhigh/vaddmul_1、16 项叶子批）。BurstTree 的底层要用纵向内核，所以它们必须在 L0 |
| 算法模板（ISA 无关） | `src/fp/alg/*.hpp` | `template<class P> …`，P 是内核提供者。仓库已有先例 `reciprocal<Factory>` |
| 提供者 `portable` | `src/fp/provider/portable.hpp` | `unsigned __int128` C++；用作测试参考，也是移植新 ISA 的起点 |
| 提供者 `x86adx` | `src/fp/provider/x86adx.hpp` | 包装上面的 L0 定长内核（x86-64-v3 + ADX，即 common 组标志 `-march=x86-64-v3 -madx`） |
| 提供者 `x86v4ifma` | `src/fp/provider/x86v4ifma.hpp` | 继承 x86adx，包装上面的 L0 IFMA 内核（u52 链式驻留、线性遍、纵向 8 道），只做包装不放内核；M1 整函数内核生成到 `src/fp/gen/` |
| 实例化 TU | `src/instances/x86v4ifma/fp_*.cpp` | **全部放在 native 组**，-O3；一个函数族的 L1 和 L2 放在同一个 TU |
| bit-burst 执行器（L0） | `src/series/burst*` | 层同步执行器 BurstTree，由浮点层和常数/原子生产者共用（§3.7）；`src/fp/alg/burst.hpp` 只负责切片和计划的胶水 |

**为什么全部放在 native 组**：native 的编译标志是 common 的超集，标量代码在 native 组里照样能编译；L1 和 L2 在同一个 TU，就能完全内联，不需要 LTO。剩下唯一的边界是"用户 → 库"，约 0.5 ns。

S 段的 add/sub/mul/sqr/fma 可以按 decimal 的先例做 `inline_export`，但它只对用 native ThinLTO 链接的调用方生效（需要在 build.py 中新增一个 fp-inline 目标）。所以目标表里的数字一律在普通归档上测，inline 带来的收益单独报告。

提供者必须暴露的原语（不只是乘法）：

| 类别 | 原语 |
|---|---|
| 乘法 | `mul<N>`、`sqr<N>`、`mulhigh<N>`→err、`sqrhigh<N>`、`mulmid<N>`；动态 n 版本；预备操作数（频谱） |
| 线性 | `add_n<N>`、`sub_n<N>`、`add_shift<N>`（对齐加，返回进位/粘滞位）、`mul_1`、`addmul_1`、`lincomb<N,K>`（Σc_k·T_k，c_k < 2^52，延迟进位） |
| u52 域 | `dot_k`、`shiftadd`、`rowsum`、`normalize`、`to_u52`/`from_u52`；提供者自定义的定点寄存器类型 `P::reg<N>` 及其运算（u52 链式驻留） |
| 除法 | `div_1`/`div_2`（预逆元流式）、小尺寸 Newton |
| 纵向（批量） | `lanes`、`vmul<N>`、`vmulhigh<N>`、`vaddmul_1<N>`、`vnorm<N>`、`vpermi2q` 表查找 |

**中间积的复用**：M2 直接用现有的 `u52::middle` / `middle_guard_zero2`（定义域：⌈64·an/52⌉ > 6、bn ≥ an、bn ≤ 8192，an 超过 1024 个数位时另需 b − a + 7 ≤ 64，见 `src/backend/u52/kernels.hpp`）；M3 用 `pq16::cyclic_multiply` / `cyclic_tail_multiply`。只有 S 段和 M1 的寄存器驻留形式需要新写中间积内核：S 段 n ≤ 4 不在 `u52::middle` 的定义域内；n = 5–8 在域内，但每次调用有 5–8 ns 的 Frame/转换开销，不可接受（§3.3）。

**参数**（约化深度 r、块大小 m、重构方式、阈值）随提供者和微架构变化：用标量线性遍时，最优 r 要小 20–40% [模型]；同一个 x86v4ifma 二进制跑在 Zen 4（zmm 双泵）或 Intel 上时，IFMA 吞吐和 mulx/IFMA 交叉点都不同。所以调参文件按（提供者, 微架构）分开：`config/float-tune/<provider>-<uarch>.json` 生成 `src/fp/provider/gen/<provider>-tune.hpp`，算法代码通过 `P::tune` 读取。

**将来的 ISA**：

- AVX2：横向用同一套 ADX 内核；纵向用 `vpmuludq`，4 道，基数 2^28–2^30。
- AVX-IFMA：ymm 上的 `vpmadd52`。
- AArch64：`mul` + `umulh`，Comba 列求和。
- NEON：只做批量，`umull/umlal` 32×32。
- SVE2：`adclb/adclt`，与向量长度无关。

如果将来需要运行时多 ISA 分派，只在算子粒度做：每个 ISA 一张函数表，首次使用时选定。

### 1.6 代码生成

入口是 `tools/generate_float.py`（`--check` / `--write` / `--verify` / `--explain`），清单是 `config/float-gen.json`。生成物提交进仓库。`build.py` 把 `--check` 作为第五个预检，目标 < 0.5 s。同一个生成器也负责从 `config/float-tune/*.json` 生成调参头文件，不走 `generate_tuning.py` 的 profile 流程：那套流程要求证据哈希，与"旧 run 直接删除"的留存规则冲突。被调参文件引用的 run 不删除。

### 1.8 球层误差传播

每次 L2 初等函数调用只做一次：

```
1. 快路径检查（偏置指数 OR，一次判断）；否则进慢路径（哨兵、n=0）
2. 若输入不精确：在 xd（带 int64 指数的 double，向上舍入）中算绝对传播界 prop
     exp:  y_up·expm1(r)        r ≤ 1 时可用 y_up·r(1+r)；更大的 r 在 xd 中直接算 expm1
     log:  r/(m−r)               (m > r)
     sqrt: r/(√m + √(m−r))
     sin/cos: min(r, 2)
     atan: r/(1 + max(0, |m|−r)²)
     agm:  M_up·max(r_a/a, r_b/b)
     rootn: |y|_up·ε/(n(1−ε))   ε = r/|m| < 1，|y| = 2^h·α（§4.4）
3. 降精度（按内核误差类型分）：
     相对误差内核（exp、log、atan 等）：
                   n = clamp(⌈(log2(|y_up|/prop) + 2 + c_f)/64⌉, 1, n_req)
                   （|y_up| 是 xd 中向上舍入的估计，n 只会偏大）
     绝对误差内核（sin、cos，所有参数，§4.7；|y| ≤ 1）：
                   n = clamp(⌈(−log2(prop) + 2 + c_f)/64⌉, 1, n_req)
     tan = S/C：内核误差约 √2·2^(c_f−64n)/cos²，与 prop ≈ r/cos² 同按 1/cos² 放大，所以按输入半径取：
                   n = clamp(⌈(−log2(r) + 2.5 + c_f)/64⌉, 1, n_req)
     xd 给不出可靠的 |y| 估计（或估计为 0）时取 n_req
4. err = raw::f<P>(y, mid(x), n)               // 调用一次 L1
5. rad = to_ulps_up(prop) + err；溢出则丢 limb
```

- 精确输入（rad = 0）跳过第 2、3 步和第 5 步中的 prop 项，只剩一次比较。
- 第 3 步的 +2 + c_f 保证 L1 误差 ≤ prop/4，半径 ≤1.25 prop。对绝对误差内核用相对公式会出错：例如 p = 1024、m 为舍入到 1024 bit 的 π、r = 2^−900 时 |sin m| < 2^−1000，相对公式给 n = 1，半径约 2^−64，丢掉约 836 位；|x| < π/4 时同样如此（m = 2^−500、r = 2^−600 时相对公式给 n = 2，丢掉约 475 位）。tan 若套用绝对公式，在 cos y = 2^−200 处会丢掉约 390 位。
- 纯 double 在 p > 1022 bit 时相对半径会下溢，所以用 xd = {double m; int64 e}。
- 基本运算的降精度按**结果**的绝对半径计算，而不是取输入 limb 数的最小值：n_out = clamp(⌈(e_c − log2 rad_c + 2)/64⌉, 1, min(n_req, 容量))。量级不同的操作数相加时这样不会白白丢位，相消时也能正确降精度。

## 2. 性能目标

### 2.1 定义

- **主指标**：warm、单线程、独立调用（吞吐模式）的单次调用耗时。调用方不持有跨调用状态；进程级缓存（常数、约化表、FFT 表与形状、计划、原子库）已热，对我们和竞品一视同仁。≤8 limb 时另报延迟模式，只作诊断。
- **被测形式**：没有标 L1 的行都是 L2 目标，在 `_into` 形式上测，输出预先分配，链接普通归档。初等函数用精确输入（竞品也是）。L2 基本运算（mul、add、fma）用不精确输入（rad ≠ 0）测，这样半径预算对应的代码确实会执行：mul +0.9、add +1.5 ns [实测，`rad.csv` 变体 U]，fma +2.0 ns [假设，实验 #20 核对]。mul、add 的精确输入另有一行（`mul_l2e`、`add_l2e`，L1 + 0.3 ns，只多一次 rad = 0 分支 [实测，`rad.csv` mulx 行]）。
- **比较对象**：该点最快的 warm 竞品，不区分点与球（§0）。例外：基本运算的 L2 行以球竞品（arb、mp_real）为参照，与点竞品（nfloat、arf、MPFR）的比较由同精度的 L1 行承担。S 段取同一 limb 数区间内竞品最便宜的那个点，这是最严的参照：竞品在 p ≈ 64n − 12 处仍用 n 个 limb，而在 p = 64n 处已经多付了一个 limb。fbench 的竞品集合直接取 `targets.py` 的 `COMP`。
- **取值规则**（`targets.py` 实现）：
  - S 段按 limb 数给值；
  - 512 bit 以上按锚点给值，锚点之间做 log–log 插值，因此目标对 p 单调。513–1023 bit 由 S 段 n = 8 的值插值到 1024 bit 锚点，所有这样插值的函数都低于 M 段基础模型（576 bit 的 exp 为 0.67×，div 为 0.67×；832 bit 的 div 为 0.56×）。这一段假定 S 段定长内核（初等函数与 div/sqrt/rsqrt）延伸到 n ≤ 16；单靠 M1 整函数内核不够（它省 20–30%，576 bit 的 exp 需要 33%）。列入 §6.3，由实验 #23 裁决；不采纳时按章程 §8 放宽并给下界论证；
  - 2^20 bit 以上（X 段）给 M_sbn 的倍数，因为那里没有竞品数据（§2.5）。M_sbn 取 `m-curve.csv` 的 libsbn 列，已测到 2^24 bit；2^20–2^22 bit 在 1M 锚点与 XM·M_sbn(2^22) 之间插值；
  - 冷启动行（`OP.cold`，2^16–2^20 bit）取竞品首次调用的 0.5 倍（§2.5）。
- **锚点值的来源**：
  - 1024–16384 bit：min(段系数 × 最佳竞品, 1.3 × 校准模型)；
  - 65536 bit：M 段模型只标定到 16k，64k 是外推，所以取 min(段系数 × 最佳竞品, 1.1 × 保守模型)，即 exp 240 µs、log 198 µs、atan 242 µs、sin_cos 320 µs、AGM 356 µs（div、sqrt、rsqrt 也满足这条）；
  - S 段：1.1–1.5 × 模型（exp n = 4/8 约 1.4×，sqrt n = 4 为 1.5×，rsqrt n = 4/8 为 1.47× / 1.49×）；
  - 再与 S、M、H 三份模型核对。低于保守模型或基础模型的格子在 §2.2 中注明依赖哪项优化，并列入 §6.3。
- **派生函数**以我方原语为单位定目标。在 64–4096 bit 的锚点上，派生函数的最佳竞品（arb/MPFR）是前沿 exp（mp_real 球）的 1.5–10 倍，是该竞品自己 exp 的 0.8–3.5 倍 [实测，`warm1.csv`、`warm2.csv`]。按竞品定目标会太松。

### 2.5 冷启动、批量、多线程、X 段

## 3. 共享构件

### 3.1 S 段定长标量内核（L0 生成）

**乘法类**

- `mulhigh<n>`：保留 i + j ≥ n − 1 的对角线，共 n(n+1)/2 次积，误差 < n ulp；再加上第 n − 2 条对角线的高半部分（n − 1 次 mulx），误差降到 < 2 ulp。两种都生成，输入半径已 ≥ n ulp 时球层用便宜的那种。
- 噪声匹配变体：输入半径 R ≥ 2^k ulp 时，低于 R·2^−3 的对角线也可以丢掉 [假设，B2/B3 输入不精确时省 10–40%]。
- `sqrhigh<n>` 在 n ≥ 6 时约为 mulhigh 的 0.55–0.6；n ≤ 4 时为 0.7–0.95（n = 1 两者都是一次 mulx）。
- 性能门槛 [实测，`warm2.csv` 中 `sbn,mul_basecase`、`flint,mul_n`、`flint,mulhigh_n`、`flint,sqrhigh` 各行]：
  - 全积 ≤1.1 c / limb 积。mulx 的上限是 0.67 c；现有公开的 `sbn3_mul_basecase` 为 1.73–1.8 c，FLINT 为 1.17 c。
  - mulhigh 不慢于 FLINT：n = 2…8 时依次为 1.8 / 2.0 / 3.1 / 4.5 / 7.0 / 8.2 / 10.6 ns。
- `sbn3_mul_basecase` 在 n = 7 有断崖（12.6 → 20.6 ns）：≤6×6 走 ADX 汇编，之后换成非 ADX 的 `mul_1` + `addmul_2` 行。生成的 L0 内核同时用来修复它。
- 规格化移位一律无分支（`shld`/cmov）。对随机尾数，按最高位分支约有 50% 预测失败（`rad.cpp` 的首版就踩到过）。

**加减**：每个 n 生成一个直线内核。

1. 指数差 d 拆成两部分：limb 移位 q = d >> 6，分三路（d = 0、d < 64n、d ≥ 64n）；位移位 r = d & 63，用 n 次 `shrd`。
2. 接着做 n 次 adc。
3. 规格化：有进位时用 `shrd`，相消时用 `lzcnt` + `shld`；粘滞位单独保留。

nfloat 只特化到 4 limb，所以在 5–8 limb 要 7–9 ns [实测，`warm2.csv` nfloat add 320–512 bit]；我们特化到 8 limb（目标见 §2.3）。公开的 `sbn3_add_n` 比 `mpn_add_n` 多约 1 ns 固定开销，相当于 nfloat 一次浮点加法的 40% [实测，`warm2.csv` `sbn,add_n`]，所以 L1 的加法必须内联，不能走公开入口。

**除法与开方的种子**

- n = 1 的除法用硬件 `divq`（约 18 c 延迟）。事先把被除数规范好，使商恰好落在 [2^63, 2^64)。
- n = 2–8 用一次 `divq` 求 64 bit 倒数（GMP 的 `invert_limb`），再接 Newton + Karp–Markstein。
- sqrt/rsqrt 的种子：`sqrtsd`（约 20 c）与 `vrsqrt14sd` 并行，再做一步整数修正，不用除法。
- FP64 在 S 段有三个用途：种子、索引链（atan 比值、三角象限）、半径传播。它们走 FP 端口，与整数端口上的中点计算并行。

**代码形态**

- n ≤ 4 完全内联。n ≥ 5 时多项式步调用非内联的 `mul_hi<k>`，每次调用约 2–3 c，摊在 40–60 c 的积上占 3–8%。
- n ≤ 2 时按延迟选 Estrin 划分，因为一个 mulhigh 的延迟就有 4–9 c；n ≥ 4 时用 Horner 即可，每个 mulhigh 内部已有足够的指令级并行。
- 生成器用 Zen 5 延迟表做依赖图调度。参考：朴素 C 写的 exp n=2 延迟为 76 c，模型下限约 35–40 c。

### 3.2 IFMA u52 内核（M 段，L0）

**表示**

- 存储用 u64。计算时一条函数链全程保持冗余 u52：入口解码一次（0.25 c/limb [实测，`linpass.csv`]），出口编码一次（约 0.4 c/limb）。
- 只有要作为 IFMA 乘数的值才规范化（一遍进位，0.2 c/limb [实测，`linpass.csv`]），因为 IFMA 只读低 52 位。累加器可以保持冗余：每个 64 bit 道在溢出前能累加 2^12 项。行减法会产生有符号数位，没有问题，最后规范化时用算术右移即可。
- 内核内部的工作精度按 52 bit 数位取整：⌈(p + g)/52⌉ 个数位，g 是该方法的守护位数。1024 bit、g ≈ 14 时为 1040 bit，比按 limb 取整的 1088 bit 少约 4%。
- 除法实验曾发现"在除法的各次乘积之间保留 u52"没有收益（`experiments/docs/division-shared-progress-2026-09-22.md:73`），这与这里的做法不冲突：除法链几乎全是乘法，往返转换只占 3–7%；初等函数内核则有 40–60% 是线性遍，这些遍只有在冗余 u52 上才便宜（惰性进位、没有 adc 链、8 道并行）。

| n×1 乘加：`addmul_1` vs k 项点积（每项） | 1.47 | 0.166 | 8.9× |
| 减行：`sub_n` vs 批量行减（每行） | 1.0 | 0.14 | 7× |
| 移位加：`rshift` + `add_n` vs 冗余移位加 | 1.6 | 0.42 | 3.8× |
| 单字除 `divrem_1` | 11.4 | — | 相当于约 70 个点积项，必须移出级数循环 |
| 规范化 / 解码 | — | 0.19–0.34 / 0.25 | — |

**高半积与平方**

- u52 列跳过：W×W 数位的积只保留第 W−1−g 列及以上。省略部分 < W·β^−g 个输出 ulp（β = 2^52），所以 g = 1、W ≤ 1260 时总误差 ≤2 ulp，单侧偏低。代价约为全积的 0.51，加上收割开销为 0.55–0.6 M。
- 平方：非对角积只累加一次，用一遍加法加倍，再加上对角项。不能预先把操作数加倍，因为 2b 会超出 IFMA 读取的 52 位。
- Toom 段用 Mulders 分割：顶部 k ≈ 0.7n 做全积，其余两块递归做短积，约 0.75–0.85 M。

**M1 整函数内核**：数位不超过 40 个时，x、t、y、各次幂和累加器都放在 ≤30 个 zmm 里，表行从 L1/L2 流入。每遍固定开销从约 10 c 降到 2–5 c [假设]，在 1–2 kbit 处约省 20–30%。缺了它，1024 bit 的 exp、log、atan、sin_cos、div、sqrt、rsqrt 都达不到目标（§2.2 中已注明）。

### 3.3 中大尺寸乘法接入

- 直接调用 `u52::multiply` / `pq16` 内核，scratch 用 `Frame::external`，不走公开的规划型 C 入口；后者每次调用有 0.35–4 µs 的固定开销 [实测，`experiments/docs/flint37-mul-comparison-2026-10-07.md`]。
- **L0 要补的能力**（完整清单见 §6.5）：
  - u52 进、u52 出、不建 Frame 的入口（今天每次调用有 5–8 ns 的 Frame/分区开销，外加两次解码和一次编码）；
  - 带误差界的 IFMA mulhigh（现有 `high_prefix` 的进位提取是标量的）；
  - u52 平方；
  - k 项点积。
- **pq16 形状缓存**：按 1/8 倍频程尺寸类缓存（填充 ≤9%）。235–1024 limb 约 20 类，进程级、不可变，首次使用时填入。
- **频谱复用**：
  - 一次调用内反复出现的操作数：Horner 里的 x^m、常数 1/D、除法里的 b 和 y、AGM 里的 b；
  - 每个复用的积省 1/3 的变换；
  - 渐缩窗口的长度一直在变，所以窗口也按 1/8 倍频程尺寸类向上取整，每类保留一个频谱。
- **FFT 段的高半积**：保护型高半积在除法的 local 段比全积慢 4–11%（`experiments/docs/division-shared-progress-2026-09-22.md:72`），所以默认用全积；`pq16::cyclic_tail_multiply`（长度约 n + g，原点误差 < 2^40）作为候选，由实验 #13 裁决。
- **短操作数**：一方是精确短值（去尾零后只有 1 个 limb）时走 `mul_1`，O(n)。

### 3.4 Newton 框架

| 运算 | 每级（h ≈ n/2 + 1） | 末级 |
|---|---|---|
| 倒数 | 残差 1 − A·y 用中间积；y += y·e 用 Mh | — |
| 除法 a/b | 同倒数，到 h | Karp–Markstein：q₀ = Mh(a_top·y)，r = a − b·q₀（中间积），q = q₀ + Mh(y·r) |
| rsqrt | S(h) + 1 次 2h×2h 中间积（残差 X·y²，约 1.5–2 Mmid(h)，模型按 2 Mmid 计）+ Mh | — |
| sqrt | rsqrt 到 h | s₀ = Mh(a·y)，残差 a − s₀²（中间平方），s = s₀ + Mh(y·r)/2 |

**除法的模型代价**（含 KM，`runs/2026-10-08-design-probes/mid_model.py`）：

| 精度 | 段 | 代价 |
|---|---|---|
| 4096 bit | 基础乘段 | 约 1.5 M（313 ns） |
| 8192 bit | Toom | 约 1.0 M |
| 16k–64k bit | FFT 段 | 1.3–2.1 M |

- **种子**：double（53 bit），再在通用寄存器里做 1–2 步，共约 30–60 c。这样可以去掉现在每个 n ≤ 15 都要付的 `sbn3i_recip_u1024`（约 120 ns，约 600 c）。
- **三阶迭代**：用一次额外乘法换掉一级。mp_real 在 24–80 limb 和 ≥1000 limb 用它，rsqrt 从 32 limb 起快 8–34% [文献]。按段调。
- **大尺寸**：
  - DIVIDE/INVERSE 复用现有服务（`normalized_newton_*`，误差 < 3 ulp），实测 2.13 M_sbn（16384 limb 时 385 µs）[实测，`runs/2026-10-08-design-probes/series/out_big.tsv`]。
  - L0 新增 `SBN3_NEWTON_RSQRT_GENERAL`。残差 E = X·S − B^(n+2m)。|R − R*| ≤ 4 时 |E| < 2^4·B^(n+m)。在模 B^k − 1（k ≥ n + m + 2）下计算循环中间积，B^(n+2m) 项回绕成已知的幂 B^(n+2m−k)，可以复用 `cyclic_sub_power`。预计 2.3–2.6 M [模型]。
  - L0 新增 `MUL_RSQRT_GENERAL`：sqrt = X·rsqrt(X)，KM 末步，y 的频谱共享，预计 2.2–2.4 M [模型]。
  - 新增"预备除数"形式：一次 INVERSE 加 k 次乘法，用于成对输出（tan、共享分母、球除法中的公共分母）。
- 频谱只在一级之内共享，不跨级，因为各级的精度不同。

### 3.5 级数求值（矩形分裂）

- **形式**：P(t) = Σ_j (t^m)^j · Σ_{k<m} a_{jm+k} t^k，代价为 (m + N/m) 次 Mh 加 N 次标量运算。
- **渐缩**：第 b 块只需要窗口 L_b = ⌈(p + g − s·m·b)/64⌉；t^i 跳过 ⌊s·i/52⌋ 个前导数位。
- **块大小**：标量项用 IFMA 点积后几乎免费，模型给出的最优 m 为 4–6，比 mp_real 的 √(N/1.5) 小。
- **公分母、无除法的 Horner**：
  - 取 D = N!，系数 c_k = D/k! 是多数位整数：N ≤ 17 时 1 个数位，N ≈ 32 时最多 3 个（平均约 2 个），N ≈ 85 时最多 9 个。
  - 递推 R_b = S_b + v^m·R_{b+1} 不含除法，最后乘一次缓存好的 1/D。N > 60 时按约 3 个数位分组，每组做一次除法。
  - 相比 mp_real 的周期性除法（4096 bit 时 3 次，65536 bit 时约 11 次），每个级数省 0.3–0.6 M [模型]。
- **K 链单字除法**（L0）：
  - 被除数分成 4 段，各跑一条余数链，交错执行；串行合并 4 个余数；再用一遍 IFMA 修正，常数 ⌊B^len/d⌋ 预先算好。
  - 从 11.4 c/limb 降到约 3.5 c/limb [假设]。
  - 用于 rootn 中除以 n、系数分组、有理缩放。
- **融合 Horner 边界**：把块的点积项作为额外的单数位行，直接初始化边界 mulhigh 的累加器，每块只规范化一次（省 3–5%）。
- **全块同时点积**：每个 8 数位条带只加载一次各次幂，同时累加全部 B 个块（2B 个累加器，≤28 个 zmm）。这样 1024 limb 时的点积也能回到 L1 速度。
- **误差**：每个 Horner 步在其窗口上 ≤2 ulp；exp 总计 < 8 ulp。
- **S 段**：系数离线烘焙成定点常数，不做除法。渐缩规则：若 u < 2^−R，则 u^k 那一项只需 T − R·k bit。效果是 n = 2 时，4 次及以上的项都只是单 limb 的 mulx。

### 3.6 参数约化

| 方法 | 用于 | 机制 | 收益 / 代价 |
|---|---|---|---|
| 直接索引多级表 | exp、log、sincos，S n ≤ 2 | 表索引直接取 x 的若干比特，不需要比较链；2–3 级，每级 8 bit；所有加载在入口一次发出 | [实测，`small.csv`] exp 内核：n=1 为 2.2 ns，mp_real 为 11.7 ns（5.3×）；n=2 为 9.1 vs 24.0 ns（2.6×）；误差还更小 |
| Tang 式短值表 | exp，S n ≥ 3 | ȳ_j = exp(j·2^−bℓ) **向下**舍入成短二进制数（bℓ + b + 1 bit），表存 log ȳ_j（n+1 limb）。残差 ≥ 0，所以下一级表要多一项（j = 2^b）；也可以改用有符号索引加对称表。约化是 O(n) 的减法；重构时把短 ȳ 拼成 ≤60 bit 的因子，做 n×1 乘积 | mulx 数：n=4 从 122 降到 77，n=8 从 562 降到 302 [模型] |
| 乘性短倒数 | log、log1p | 第一级用有符号、四舍五入的索引 j₁ = round((m−1)·2^b)，m ∈ [1/√2, √2)，配负 j 的表项；\|m−1\| < 2^(−b−1) 时 j₁ = 0，x 在 1 两侧都只走多项式。第一级 c₁ = 1/(1 + j₁·2^−b)，第 ℓ ≥ 2 级 c = 1/(1 + j·2^(−bℓ−1))，都舍入成短数；u ← (1+u)·c − 1 是 n×1 运算；表存 −log c | 没有除法，也不用 atanh；log 与 exp 代价相当 |
| 共享短乘子族（候选，第 ≥4 级） | exp 与 log | Tang 的 ȳ_j 与 log 的 c 只在第 ≥4 级与 1 + j·2^−bℓ 相同（第 2 级差 2^b 个网格单位，第 3 级差 1 个）。所以第 ≥4 级两种约化都改用精确的 s = 1 + j·2^−bℓ（exp 取 j = round(t·2^bℓ)，log 取 j = −round(u·2^bℓ)，残差 ≤ 2^(−bℓ−1)(1 + O(2^−b(ℓ−2)))），共用一张 log(s) 表；第 2–3 级各用自己的表。是否采纳由实验 #1 决定 | 深层表约省 40–50% [假设，实验 #1 核对]；pow 先算 log 再算 exp，读到的行已经在缓存里 |
| 短高斯整数旋转 | sin/cos/tan、atan/atan2，S n ≥ 3 | 用短 (c̃ + i·s̃) 旋转，每级 4 次 n×1；比值链用 FP64 跟踪；末尾一次 rsqrt 归一（tan、atan 不需要归一） | sincos n=8：mulx 从 1135 降到 819 |
| 按位（BKM）约化 | exp/log（log(1+2^−i) 行），atan/sincos（atan(2^−i) 行），M 段 | 约 r/2 行用批量 rowsum 减掉；重构在 M1 用直接移位加，n ≥ 64 用积形式（先在增长中的 P 上做移位加，最后一次 Mh） | 每 bit 约 0.28·n c；而一次表乘积每 M 只换来 8–16 bit，所以 Arb 式大表在 M 段整体处于劣势 [模型] |
| 窗口比特决策 + NAF | 按位约化 | i ≥ 64 时，窗口 c 内的贪心选择等于 t 在该窗口的比特，前提是先减去此前各窗口所选行落在窗口 c 内的部分（每行 1–2 limb），其余部分最后批量 rowsum。log 变体 A 和 atan 的判据是每个窗口一次的 1 limb 商 D/P、v/u。违例概率约 2^−i，走精确回退。NAF 编码只给 log(1−2^−i) 加负行（atan 是奇函数，负行就是 −atan(2^−i)） | 行数和移位加都少 33%，exp/log/atan 约快 10–15% [假设，先用 Python 模拟验证（实验 #7）] |
| k 位短乘子约化（候选） | exp/log/atan，M1–M2 | 每 b bit（b = 3–6）一级：一次行减 + 一次 n×1 IFMA 乘加 y += (j·2^s)·y，移位折进 52 bit 乘子 | 相对带 NAF 的按位约化约快 10–15% [模型，实验 #16]；b = 4 在 1–2 kbit、b = 6 在 1 kbit 时表 ≤144 KB；b = 6 在 2–4 kbit（306 / 726 KB）以及 4 kbit 的 b = 4（346 KB）超出 §1.6 的 .rodata 预算（M 段表 ≤260 KB），只能放进常数库惰性构建；≥8 kbit 没有收益 |
| 多素数原子 | exp/sincos，H 段，原子库已热 | 原子 L_i = 2·atanh(1/m_i)，exp(L_i) = (m_i+1)/(m_i−1) 是精确有理数，从不形成 log p。要求原子的素数指数矩阵**幺模**（\|det\| = 1，作为 Størmer 搜索的约束），此时格与素数对数格相同，CVP 最优解也相同；否则约化深度损失 log2\|det\| bit。离线做 Størmer 搜索 + LLL；t = x − Σc_i·L_i 用一遍 k 项 IFMA 点积，原子按 W + ⌈log2 Σ\|c_i\|⌉ + 8 bit 读取，约化误差 ≤ Σ\|c_i\| ulp；num/den 用高度约 W/4 的积树 | 1M bit：k_at = 13 时约化 R ≈ 164 bit，k_at = 48 时约 507 bit；warm 时 exp 快 1.5–1.9×；k_at = 13 在 6–11 次调用后回本，k_at = 48 在 15–27 次 |
| Payne–Hanek 窗口 | 三角，\|x\| ≥ π/4 | x = M·2^(E−64n)。2/π 的比特取第 E−P−3 位到第 E+p+g 位，共 P+p+g+3 bit。按 limb 对齐从表中读取时起点最多浪费 63 bit，窗口取 2n + 1 + ⌈(g+3)/64⌉ 个 limb（按位移位读取则 2n + ⌈(g+3)/64⌉，多一遍 Lin）；静态表要求 E + p + g ≤ 2^17。M × 窗口做中间积，输出取 n + ⌈(g+3)/64⌉ limb 得到 frac(x·2/π)（窗口长度已对全部 64 种对齐、精确的 2/π 核对 [模型]）；只保留 q mod 4（或 8）；允许 \|r\| ≤ 1 的重叠，不做边界判定 | 额外代价 ≈ M(n) + Mh(n)，与 \|x\| 无关；在 kπ/2 附近要相对精度还需更多窗口位（只有 L3 需要） |
| 精确短残差 | 三角第一级 | u = t − j/256 精确（j/256 是短二进制数），不需要角度表 | 少一张表，也少一份残差误差 |

**逐级截断**：多级乘性约化（Tang、乘性 log、短旋转）的中间量会超出 n+1 limb：n=4 时需要 395 个小数位，而 n+1 limb 只有 320 位。所以每一级都截断到 n+1 limb，每级误差 ≤1 ulp(n+1)，计入生成器给出的误差界。n ≤ 2 的配置恰好是精确的。

**表布局**

- S 段用 limb 主序的共享布局 `tab[level][limb][j]`。每张表按 9 limb 只存一份，大小为 n 的内核只读前 n 个 limb，所以 L1 占用与 n 成正比；把正确舍入的表项截断只多 ≤0.5 ulp。S 段的表合计约 280 KB，每个函数在每个 n 下的预算 ≤24 KB。
- M 段的按位约化表（log(1+2^−i)、atan(2^−i)、log(1−2^−i)）静态存到 4096 bit。更高精度的表由常数库按租雪橇规则惰性生产：i ≤ 61 时，log(1+2^−i) = 2·atanh(1/(2^(i+1)+1)) 正好符合现有公式模式；更大的 i 用多重求和。
- 16 kbit 以上表行开始从 L3 读取，选 r 时要考虑 L2/L3 的差别（模型中 64k bit 时表流量约占 exp 的 25%）。表按索引主序、每 64 limb 一块存放，约化时连续读取。

### 3.7 bit-burst 执行器（H–X 段，L0 的 BurstTree）

**流水线**（warm exp，输出 p bit）：

0. 若 x 精确且有效高度 h ≤ c₁（例如 exp(1)、exp(3/8)），跳过第 2–4 步、折半和 Payne–Hanek，直接算一棵切片树；三角用高斯树，不做约化。h ≤ 8 bit 时约快 4 倍，h ≈ 16 时约 2 倍，h = 64 时无收益 [假设]。
1. W = p + 一个守护 limb。误差预算是计划常数，不需要像 astra 那样加 64 + 4·lg p bit。
2. 粗约化：|x| ≥ 1 时 n₂ = round(x/ln2)，ln2 从常数库取。
3. 原子库已热：多素数原子约化。冷启动：做 h 次折半（模型给出 64k–1M 时 h ≈ 16，≥4M 时 0–4）。
4. 切片：c₀，c₁ = b₀，c_{j+1} = ρ·c_j，ρ ∈ {2, 3}，由计划按代价模型选（exp 两者相差 5% 以内，三角多数选 3）。
5. 每片的项数 N_j 取满足 N·c_j + log2 N! ≥ W + 4 的最小 N。astra 用的 N = ⌈(W+2)/a⌉ 多算了 1.6–1.7 倍的项。
6. 每片计算一棵截断树 T_j，然后 N ← N·(D_j + T_j)，截断到 W。D_j = N_j! 与参数无关，是计划常数；N₀ = 1/ΠD_j 也来自计划，所以 **warm 路径上没有除法**。A_j = 0 的切片跳过，此时 N₀ 只对实际参与的切片取积（计划按切片存 1/D_j）。
7. 可选的渐缩矩形分裂尾段：三角在每个格子都选它（停在 W/32），因为每个三角切片要额外付约 2 M 的复数合成；exp 只在 64k 选它（k_at = 13 和 48 都是）。
8. 收尾：除以多素数分母（H bit 的 Newton 倒数加一次 W×H 乘法，约 1 M）；撤销折半（每次约 0.7 M）；乘 2^n₂。

**合并代数**（现在的引擎每次合并做 4 次积、10 次变换）：

| 变体 | 积 | 变换（FFT 段） | 说明 |
|---|---|---|---|
| powtab：U = A^l 来自每层一张表；每层（每个变换长度）只算一次 U_L 的频谱 | 3 | 7 | 每层一次平方 |
| + 计划持有 D 树，D_R 的频谱缓存 | 2 | 4 | D 与参数无关 |
| + MAC2/DOT2：T = T_L·D_R + U_L·T_R 在频谱域求和 | 2（融合） | **3** | pq16 `matrix_execute` 的 DOT2；NTT 的 `program_sum_execute` |

**截断树**

- BurstTree 在构建计划时，按 decay(i) = ⌊a(i−1) + log2((i−1)!)⌋ 预算每层的输出窗口 q(i)，执行时截断到这个窗口。
- 正确性只需把 `experiments/docs/series-precision-planner-math-2026-09-17.md` §5 式 (18)–(22) 的通用精度定理套到切片上；这个定理不要求 |U| ≥ 1。N ≤ 2^20 时守护位 ≤24 bit，一个守护 limb 就够。
- 现有的 `FiniteFormula::limit_words` 只在实验 #10 中使用，用来在现有引擎上验证误差和收益。注意：frame 形式下参数化的宽叶子必须 leaf_terms = 1（`src/series/arithmetic.cpp:870-875`）。

**执行器**：BurstTree 是层同步的。现在的引擎每次积调用约有 300 ns 的外围开销（`product_program_run` 的校验、按阶段容量填充、规格化移位），在 1M bit 占 37%，在 16k 占 66% [模型，已用实测校准]。

| 层级 | 节点尺寸 | 做法 |
|---|---|---|
| 底层 | ≤16 limb | 纵向 IFMA，8 个兄弟合并为一组；同一层所有节点的 U_L = A^l 都相同，直接广播；52 bit 以内的分子用 16 项精确叶子批 |
| 中层 | 16–256 limb | 直接调用 `u52::multiply`（Frame 来自调用方）；T_L·D_R + U_L·T_R 两次积融合累加，只规范化一次（L0 需要新增 u52 MAC2） |
| 顶层 | ≥256 limb | pq16/NTT；用缓存的 D_R 频谱，每层一个 U_L 频谱，DOT2 求和，输出截断到 q(i) |

同一条小节点快路径也要移植进通用的 `Merge::multiply`：π 和 e 的生产会快 1.4–1.8 倍，原子库的回本次数也随之下降。

**exp 的代价随改进的变化**（k = t/M_sbn，1M bit [模型]）：

| 改进 | k |
|---|---|
| astra 原实现 | 305 |
| 按阶乘计项数 + 一次延迟除法 | 207 |
| 低开销执行器 | 144 |
| powtab + 截断树 | 100 |
| D 树 + MAC2 | 93 |
| 多素数原子 k_at = 13 / 48 | 61 / 47 |

作为对照，mp_real 用它自己的乘法时 k = 67。

**sincos**

- 高斯切片：e^(i·x_j) 的 T 是高斯整数，D 是实数，U = i^l·A^l，powtab 仍然适用；代价约为 exp 树的 2 倍。
- 最贵的一两个切片也可以改用 sinc 树加 √(1 − s²)，由计划按片选择；c − 1 = −s²/(1+c) 不会相消。
- 高斯素数约化的分母是实的素数范数幂，可以并入 Den。于是 cos = Re N/Den，sin = Im N/Den；warm 时 N₀ = 1/Den，不需要除法。tan = Im N / Re N，只要一次除法，Den 约掉。

**线程**

- 各切片在按 LPT 划分的子 Team 上独立求值，合成是一棵积树；1/Den 和多素数积树与切片并发进行。
- 线程宽度：p < 2^17 时为 1（切片数 ≥4 时可到 2）；2^17–2^21 时 ≤8；≥2^21 时 ≤16（切片串行，片内并行分裂，NTT 积并行）。
- CCD1 在缓存密集任务上慢 10–25% [实测，`experiments/docs/log-followup-results-2026-09-17.md`]，所以用动态切片窃取，不用静态权重。

**内存**：

- 一次 exp 的工作集约为 20–30 W（1M bit 时 3–4 MB）。
- 计划缓存按尺寸类组织、按字节封顶（§1.4）；4 Mbit 以上不缓存频谱。
- W ≳ 2^33.5 bit 时 v1 返回"不支持（需要 OOC）"；OOC 版本的初等函数留到 v2。

### 3.8 常数

**静态层**：生成的认证下取整表。读取 = 指针 + 截断 + 1 ulp 半径，目标 ≤3 ns；竞品的 warm 读取为 3.8–9 ns [实测，`warm2.csv` const_* 行]。

| 常数 | 静态到 | 大小 |
|---|---|---|
| π、ln2、2/π | 2^17 bit | 各 16 KB |
| e、ln10、log2(10)、1/ln2、1/ln10、γ、Catalan、ζ(3)、√2 | 2^16 bit | 各 8 KB |

合计约 120 KB。π、ln2、2/π 存到 2^17 的理由：2^16 bit 时 libsbn 的 π 执行约 340 µs（不含 query；Arb 冷构建 476 µs），约为我方 64k exp 目标（240 µs）的 1.4 倍，H 段下沿的参数约化不应该付这笔钱。Catalan 必须进静态表：FLINT 没有，64 bit 冷读也要 1.5 µs。γ 在 FLINT 的静态表只到约 2.9 kbit，超出后冷构建要 269 µs [实测，`warm2.csv`]。

**动态层**：进程级。

- 每个常数一个不可变缓冲，原子发布 (limbs*, n, exp, err)；不够时单飞增长到 max(need + 1, 2·cur)。
- 旧缓冲保留到进程结束，持有前缀的读者始终有效；总工作量不超过最大一次计算的 2 倍。
- **认证机制**：用近似入口（返回值 + 误差单位）算到 P + 64 bit；若守护 limb 离进位边界的距离大于误差，就存下取整，否则再加 64 bit 重算。这个过程从不中止。

**生产者**（都在 L0，用级数引擎）：

| 常数 | 公式 | 现状 [实测，`runs/2026-10-08-design-probes/series/`] |
|---|---|---|
| π | Chudnovsky（PSR、比值终端、mul_rsqrt） | 1M bit 单线程执行 7.3 ms，Arb 冷构建 15.7 ms；1B 位数时为 y-cruncher 的 1.01× |
| e | Euler 级数 | 1M bit 2.65 ms（Arb 6.37 ms） |
| ln2 | 2·ArcCoth(3)（加速级数） | 1M bit 12.6 ms（Arb 31.3 ms） |
| ln10 | 3·L(3/253) + 10·L(1/9)（有理 atanh） | y-cruncher 的 0.50–0.76× |
| 2/π、1/ln2、1/ln10、log2(10) | INVERSE 或乘法派生 | 约 1.6 M |
| γ | Brent–McMillan；需要新的（P,Q,T,C,D,V）合并配方（约 7–8 次积），必须 PSR 截断 | 未实现；Arb 冷构建是冷 π 的 24 倍 |
| Catalan | Pilehrood/Guillera 型超几何级数，符合现有 P/Q/R 模式 [假设] | 只有 BBP 数字提取 |
| ζ(3) | Amdeberhan–Zeilberger | y-cruncher 的 0.83–0.95× |

L0 需要的改动：

- π/e 的**近似入口**：不做下取整认证，因此不会中止。公式路径已有 `formula_execute_approximate`。
- **Frame 形式的生产者**：PSR 只有 arena 形式，arena 必须 mlock，而本机 `ulimit -l` 只有 8 MiB；单线程的 π 从 16384 limb 起要用 PSR。
- 用闭式计算停止下标，替代现在在 2^40 探测域上的搜索。
- 用 `ProductDecisionLog` 重放积的选择。计划目标 ≤50 µs，现在 π 的 query 要 0.45–0.9 ms。
- §3.7 的小节点快路径（P3 交付，连同它底层用的 L0 纵向 IFMA 内核与 u52 MAC2）。

**目标**（P3 验收）：冷构建（含计划）在 1M bit 时，π ≤5.0 ms，e ≤1.8 ms，ln2 ≤9.0 ms，约为 Arb 的 0.3 倍。

依赖图必须无环：级数常数 → 原子和按位表 → 各种约化。生产者绝不调用通用的 exp/log。Gauss–Legendre π 和 AGM ln2 只作为测试中的独立对照：它们在 2^20 limb 时比级数慢 3.5–6 倍。

## 4. 各函数详细设计

每节依次给出：各段算法 → 误差与球 → 优化点（编号，附预期收益）→ 调参参数 → 决定设计的实验。目标数值见 §2。

### 4.1 加、减

**算法**

- **S 段**（n ≤ 8）：每个 (n, 情形) 生成一个直线内核（§3.1）。
  - 同号：交换操作数使 e_a ≥ e_b（cmp + 2 次 cmov）；b 右移 d 位；有进位时整体右移 1 位、指数加 1。
  - 异号：d ≤ 1 时可能灾难性相消，用 `lzcnt` + `shlx` 精确处理，被移出的那一位作为第 65 位保留；d ≥ 2 时最多规格化 1 位。
  - 估计 [假设]：1.2–1.8 / 1.6–2.2 / 2.5–3.5 / 4–6 ns（n = 1/2/4/8）。
- **指数差快路径**：较小的操作数整个落在结果 ulp 之下时（d > 64n + 1），结果就是较大的操作数，半径加 1。代价 O(1)，原地运算时不拷贝。
- **M 段起**：用 VBMI2 `vpshrdvq`/`vpshldvq` 做移位，与 adc 链融合成一遍。实测数据通路为 0.27–0.4 c/limb，大尺寸受 adc 链限制，约 1 c/limb。目标：9–32 limb ≤0.6× 最佳竞品；64–1023 limb ≤1.15× `sbn3_add_n`；≥1024 limb ≤1.05×（依赖实验 #17，§2.2）。
- **超大 n**：试验 AVX-512 掩码进位前瞻。做法是用 `vpcmpuq` 得到生成/传播掩码，在 k 寄存器上做加法求出进位向量，再做一次掩码 +1 [假设，未验证]。

**球**

- rad_c = ⌈rad_a·2^(u_a−u_c)⌉ + ⌈rad_b·2^(u_b−u_c)⌉ + 粘滞位，u 是各自的 ulp 指数。
- 相消时半径左移；左移到饱和后走丢 limb 路径。
- 降精度按结果的绝对半径计算（§1.8）。
- 两个精确值的和如果放得下，结果就是精确的，存储时去尾零。

**优化点**

1. 半径更新是加法里最贵的部分（吞吐 +1.4 ns，n = 1 时延迟 +4 ns [实测，`rad.csv`]）。办法：预先算好向上取整的移位量，并为 d = 0 和精确输入特化。
2. 一直特化到 8 limb。竞品只特化到 2–4 limb：nfloat 在 5–8 limb 要 7–9 ns，MPFR 要 7.8–11 ns。
3. 指数差是 limb 整数倍时，只需 limb 移位；不是整数倍时，位移位也融合进 adc 链（MPFR 在非对齐时要多付 1.05–1.1 倍）。
4. `inline_export`（只对 ThinLTO 调用方有效，§1.5）。

**实验**：#2（生成的加法内核，与 `nfloat_add` 比较）；#17（大 n 掩码进位）。

### 4.2 乘、平方、fma、点积

**算法**

| 段 | mul | sqr |
|---|---|---|
| S | 生成的 `mulhigh<n>`（误差 < 2 ulp）；输入半径够大时由球层改用便宜变体（< n ulp） | `sqrhigh<n>` |
| 9–~14 limb | 标量 mulhigh 与 u52 mulhigh 的交叉点要实测：没有 u52 短积时约在 13–15 limb，有了约在 9 limb [模型，`warm2.csv`] | 同左 |
| M2 | u52 列跳过 mulhigh；Toom 段用 Mulders 短积 | 非对角积只累加一次，再加倍 |
| M3–X | pq16/NTT 全积，形状缓存；同一乘数反复出现时复用频谱 | 省一次正变换（约 0.67 M） |

- 精确 × 精确，且 n_x + n_y ≤ n：结果精确，做全积。
- 一方是 1 limb 的精确值：走 `mul_1`，O(n)。
- 乘以 2 的幂只改指数；乘以小整数用 `mul_1`。

**球**

- R_c = ((mulhi(hiA, R_b) + mulhi(hiB, R_a) + 4 + [n=1]·mulhi(R_a, R_b) + [n≤2]) << s) + err_kernel，其中 hiX 是最高 limb，s 是规格化移位。
- n = 2 时 +4 不够，审查用反例证实了这一点（`check3.py`），所以多加 1。n ≥ 3 时 +4 够用。
- 两次 mulhi 不在中点的关键路径上。

**fma**：单次舍入。S 段做精确积（n = 1 时一次 mulx），加到 128 bit 上再规格化，半径 1 ulp 而不是 2。更大尺寸时做 mulhigh 到 n+1 limb 再加。竞品的 fma 在 64–128 bit 是 mul + add 的 1.0–2.5 倍，在 256–512 bit 是 0.73–0.98 倍，≥1 kbit 约为 1.0 倍 [实测，`warm2.csv` fma 行与 `warm1.csv` mul 行]。我们的目标是不慢于我方 mul 与 add 之和。

**点积**（矩形分裂、矩阵、多项式都要用）：

- 第一遍求最大指数和半径指数。
- 用一个 (n+1) 字补码定点累加器装下整个中点点积，每项只按它的量级所需的精度计算。
- 半径用单字累加器（34 位空余）；精确输入跳过半径计算。
- 误差 ≤ N(n+2) ulp [文献，AJ25 Thm 7]。M 段用 k 项 IFMA 点积。
- 批量和向量的情形可以共享一个半径指数（§4.14）。

**优化点**

1. 生成的汇编要逼近 1.0–1.4 c/limb 积。现在的 8×8 走非 ADX 的 `addmul_2` 路径，用 121 c（约 1.9 c/三元组），有 1.35–1.9 倍的余地。
2. 噪声匹配 mulhigh（§3.1）。
3. 同一乘数的频谱复用；为 Horner 这类场景提供"预备乘数"的内部接口。
4. 去尾零的精确短值（小整数、短二进制小数）走短路径。这在用户代码里很常见，但随机输入的基准测不到 [假设，≥512 bit 时快 3–10 倍]。

**实验**：

- #2：生成的 `mulhigh/sqrhigh<1..8>` 对 FLINT。
- #3：u52 列跳过在 20/40/79 数位的实际比率，以及标量与 u52 的交叉点。`u52::high_prefix` 以 an = n+2（低 2 字为零）调用，计入每次的 u52 转换；它的误差口径更严（≤1 ulp），只作上界参考。
- #13：`cyclic_tail_multiply`。
- #19：噪声匹配 mulhigh。

### 4.3 除法与倒数

**先分流特殊形状**：

- 除数是 2 的幂 → 只改指数。
- 除数去尾零后只有 1 limb → 预逆元流式 `div_1`，O(n)。
- 除数有 2 ≤ k < n/2 limb → 分块除法，k limb 逆元预先算好，代价 O(n/k·M(k))。
- 有效宽度的扫描限制在 O(n) 个字以内。

| 段 | 算法 | 估计 |
|---|---|---|
| S n=1 | 被除数预先规范，使商落在 [2^63, 2^64)，一次 `divq`；余数为 0 时结果精确 | 延迟约 22 c；吞吐 2–3 ns [假设] |
| S n=2 | v = ⌊(2^128−1)/b₁⌋ − 2^64（一次 `divq`），q₀ = mulhi(a₁, v) + a₁，R = a − q₀·b（2 次 mulx），q₁ = mulhi(R_top, v) + R_top | 约 6 次 mulx + 1 次 div，5–6 ns |
| S n=4 | 128 bit 倒数，一步 Newton 到 256 bit（4×2 中间积约 6 次 mulx，r·e 4 次），再做 KM | 约 32 次 mulx + div，约 12 ns |
| S n=8 | 64 → 128 → 256 → 512，再做 KM | 约 100 次 mulx，约 32 ns |
| M1 | 生成的寄存器驻留 Newton：倒数到 9 limb 约 120 c，KM 约 200 c | 16 limb 时 65–80 ns |
| M2–M3 | §3.4；b 和 y 的频谱复用 | 约 1.5 M（4096）/ 1.0 M（8192）/ 1.3–2.1 M（16k–64k）[模型] |
| H–X | Newton DIVIDE/INVERSE 服务，误差 < 3 ulp；走计划缓存 | 2.13 M [实测，`series/out_big.tsv` divide 16384] |

**球**：|b| > r_b 时，rad ≤ (|a|·r_b + |b|·r_a)/(|b|·(|b| − r_b)) + 内核误差，在 xd 中计算。b 的相对半径 > 2^−30 时走慢路径，结果可能是宽球或不定。

**倒数**：省掉最后一次乘法，代价约为除法的 0.6–0.8。

**优化点**

1. 去掉 1024 bit 倒数种子（§3.4），小尺寸每次省约 120 ns。
2. KM 末步融合。
3. 残差用中间积。
4. 按段选择二阶或三阶迭代。
5. 预备除数接口：反复除以同一个数时，只做一次 INVERSE，之后每次只是一次乘法。
6. 级数里除以小整数，一律走 `div_1` 或 K 链（§3.5），不走一般除法。

### 4.4 sqrt、rsqrt、rootn、cbrt

**S n=1 的 sqrt**

1. xd = cvt(m >> 11)·2^k，得到精确的 53 bit。
2. sd = `sqrtsd`(xd)；同时并行算 rd = `vrsqrt14sd`(xd)（14 bit）。
3. s₀ = cvttsd2si(sd·2^j)，有 53 bit 正确。
4. R = A − s₀²，用 mulx 加减法得到精确的 128 bit。
5. s = s₀ + mulhi(R', rd')/2。误差 ≲ 2^−53·2^−14 + 2^−106，即 ≤1 ulp。

延迟约 38 c，吞吐约 10–12 c。内核本身 2.0–2.4 ns，加上入口约 2.5–4 ns；MPFR 为 7.23 ns。

**其他 S 段情形**

- **n=1 的 rsqrt**：`vrsqrt14sd` + 两步 FMA Newton（到 52 bit）+ 一步整数修正，3–4 ns。所有竞品在这里都走通用路径（≥57 ns）。
- **n=2 的 sqrt**：先用 double 算 rsqrt 种子；做一步整数 Newton r₁ = r₀ + r₀(1 − a·r₀²)/2（7 次 mulx）；再做 KM：s₀ = mulhi(a₁, r₁)，s = s₀ + r₁(a − s₀²)/2（5 次 mulx）。共约 7 ns。
- **n=4/8**：再加一到两级 Newton，用短积和中间积，约 18 / 40 ns。rsqrt 去掉 KM 末步，约 15 / 35 ns。

**M 段**：用 §3.4 的 rsqrt Newton，sqrt 用融合 KM（把现有的 `mul_rsqrt` 从 u64 被开方数推广到一般被开方数）。

| 精度 | 做法或模型代价 |
|---|---|
| 1024 bit | 用生成的 M1 内核，85–100 ns |
| 4096 bit | 约 2.0 M |
| 8–16 kbit | 1.3–1.5 M |
| 64 kbit | 约 2.5 M |

[模型，`mid_model.py`]

**H–X 段**：用 L0 新增的 `RSQRT_GENERAL` / `MUL_RSQRT_GENERAL`（§3.4）。

**rootn（整数 n）**

- **规范化**：写 x = m·2^T，取 T = n·h + k，其中 −⌊n/2⌋ ≤ k < ⌈n/2⌉；令 A = m·2^k，α = A^(1/n) ∈ (½, 2)，则 x^(1/n) = 2^h·α。
- **大 n 捷径**：令 c = (|k|+1)/n，则 |log α| < c；c ≤ ½ 时 |α − 1| ≤ 2c。若这在误差预算内，直接返回 2^h。
- **迭代**：无除法的逆根 Newton r ← r + r(1 − A·rⁿ)/n，根 = A·r^(n−1)。
  - 除以 n 必须精确：用 `div_1` 或 K 链单字除法，代价 O(p)。如果用常数 1/n，它的精度不能低于本级目标。单 limb 的 1/n 会让每一步最多只增加 64 bit，二次收敛就没了。
- **三阶变体**（同样无除法）：r⁺ = r·[1 + e/n + (n+1)e²/(2n²)]，e = 1 − A·rⁿ，新误差为 O(e³)，精度阶梯每次乘 3。
- **种子**：double 的 `pow`/`cbrt`（30–60 c），接受条件 |v − 1| ≤ 1/32；冷路径回退到二分。
- **代价**：每级约 (log2 n + 2)·M（rⁿ 用二进制幂，渐缩积）。n = 2 直接走 sqrt；n = 3 用耦合的 y³ 步。

**球**

- sqrt：半径 ≤ r/(√m + √(m−r))。
- rsqrt：半径 ≤ r/(2(m−r)^(3/2))。
- rootn：相对半径 ≤ ε/(n(1−ε))，ε = r/|m| < 1。也可以在 xd 中向上舍入地算 1 − (1−ε)^(1/n)。
- Newton 残差证书：ρ = |A/yⁿ − 1| ≤ ½ 时 |α − y| ≤ 2yρ/n。逆根迭代中 A/yⁿ = (1−e)^−(n−1)，即 ρ ≈ (n−1)|e|，不能直接把 e 代入。它只用于内核误差，不用于输入半径的传播；球层的绝对半径要乘 2^h（§1.8）。

**优化点**

1. FP64 种子与整数修正在不同执行端口上并行。
2. 修正步不用除法。
3. KM 末步融合。
4. 一级之内频谱共享（现有的 rsqrt 级已经用同一个 R 频谱算缓存的 SQR 和 MUL）。
5. 三阶 rsqrt。
6. 完全平方 / 完全 n 次幂检测：只在输入精确且短时做，结果精确。L3 的精确性测试也要用到它。

### 4.5 exp 族（exp、expm1、exp2、exp10、sinh、cosh、tanh）

**约化**

- **符号**：exp/expm1 按符号—绝对值处理。N 从 |x| 求出；x < 0 时用 exp(−|x|) = 2^−k·T⁻[j₁]·e^−r，T⁻ 是 2^(−j/256) 表，这样 (T−1) 与 T·q 同号，不会相消。另一种做法是用四舍五入的 N 配有符号的 r，并在 |x| < ln2/512 时走只算 q 的直通路径。
- **融合约化**：N = ⌊|x|·256/ln2⌋ 用一次 mulx（输入 x_top·2^s），k = N >> 8，j₁ = N & 255。然后 r = |x| − N·ln2/256 ∈ [0, ln2/256)，所以 T1[j] = 2^(j/256)，第二级的索引取 r 的比特。用 x_top 求出的 N 可能差 1，内核要对 r 做一次比较和修正。**定义域**：单次 mulx 只用于 |x| < 2^40（E ≤ 54 时 N < 2^63 且误差 ≤1）；更大的 |x|（E ≤ 61，N 最多约 70 bit）用 2 limb 的 x 与 256/ln2 求 N，ln2/256 取 n + 2 limb。否则 E = 61 时 N 会错约 90，一次修正不够，内核会索引错表项而误报小误差。下面实测的 n=1 原型是**未融合**的版本：它直接对 x ∈ [0,1) 的比特索引 exp(j/256) 表，没有 ln2 约化。
- **范围**：|x| > 2^61·ln2 时上溢或下溢，所以 E ≤ 61，ln2 最多需要 p + g + 61 bit。p + g + 61 ≤ 2^17 时用静态表就够了。上溢/下溢在开始计算之前由 k 判定。

**S 段**

- **n=1**，已实测，未融合原型（37 条指令，5 次 mulx，两级表共 4 KB）：
  ```
  j1 = X>>56; j2 = (X>>48)&255; V = X<<16          // u = X mod 2^48 < 2^-16
  E12 = T1[j1] + round(T1[j1]·F2[j2])              // T1 = exp(j/2^8)·2^62，F2 = expm1(j/2^16)·2^64
  W = mulhi(V,V); a = mulhi(V,1/6); t3 = mulhi(W,a) // 类 Estrin，深度 2 次 mulx
  q79 = V>>1 + W>>18 + t3>>33                       // (e^u − 1)·2^79
  R = E12 + (E12·q79)>>79；按第 63 位 cmov 规格化
  ```
  吞吐 2.2 ns，延迟 4.2 ns，误差 ≤3.35 ulp。紧变体（T1 存 2 limb）误差 ≤0.52 ulp，吞吐 4.0 ns；mp_real 在 p = 64 时必须走它的 2 limb 内核，紧变体比那个快 6 倍 [实测，`small.csv`]。
- **n=2**，已实测：3 级 × 8 bit，u < 2^−24，5 次多项式，3 次以上的项都是单 limb 运算；H = G + q + G·q，R = E₁ + E₁·H。吞吐 9.1 ns，延迟 15.1 ns，误差 ≤2.02 ulp。2 级 + 7 次多项式的变体是 10.6 ns，印证了模型的结论：级数多、多项式次数低更好。
- **n ≥ 3**：Tang 式短值表（§3.6）。
  - n = 4：L = 6 级 × 6 bit，6 次多项式，77 次 mulx，约 28 ns。
  - n = 8：L = 9 级 × 5 bit，10 次多项式，302 次 mulx，约 100 ns。

**变体**（与 exp 共享约化和级数，只在重构上不同）

- **expm1**：小 |x|（k = 0 且 j₁ = 0）时输出 q，不会相消；但 q 必须在以 |x| 的量级为基准的网格上求值（先把 x 左移 lzcnt 位，渐缩规则按 |x| 计），或 |x| < 2^−60 时走缩放的 expm1 内核，否则定点截断给出的相对误差是 2^−64(n+1)/|x|（n = 1 原型在 2^−79 网格上算 q，|x| < 2^−18 时就已不满足 64n − c_f）。这个截断点写进 `//@` 规格（相对输出网格）；sinh、tanh 在 0 附近同样处理。否则用 (T−1) + T·q（表里本来存的就是 expm1），x < 0 时按上面的符号处理。M/H 段撤销折半时始终保持 u = e^r − 1，用 u ← u(2+u)。
- **exp2**：x = k + f 可以精确拆开，只有 f·ln2 需要 ln2，而且只需要 p bit。exp10 用 x·log2(10)（静态常数）。
- **sinh**：sinh x = ½(u + u/(1+u))，u = expm1(|x|)。任何 x 都不会相消，只需一次倒数，也不需要单独为 |x| < 2^−8 写奇级数。
- **cosh**：cosh = ½(E + 1/E)。sinh_cosh 同时输出两者。S 段也可以用奇偶拆分，一次 Horner 同时得到 e^u 和 e^−u（表存 T(±j)）。
- **大 |x|**：sinh、cosh 用 exp(a − ln2) 并带误差界丢掉 e^−a/2，避免提前一个 binade 溢出。
- **tanh**：tanh = w/(w+2)，w = expm1(2|x|)，一次除法；大 |x| 时 |tanh a − 1| ≤ 2e^(−2a)，直接饱和。

**球**：exp(m ± r) 的半径 = y_up·expm1(r) + 求值误差（§1.8）。

### 4.6 log 族（log、log1p、log2、log10、asinh、acosh、atanh）

**约化**：x = 2^k·m，m ∈ [1/√2, √2)，这样 k·ln2 + log m 不会相消。|x − 1| 很小时保留精确的 δ = x − 1，走 log1p。

**S 段：乘性短倒数约化**（§3.6）

1. 第一级：有符号、四舍五入的索引 j₁ = round((m−1)·2^b)；c₁ = 1/(1 + j₁·2^−b) 舍入成 b + 2 bit；u₁ = m·c₁ − 1（n×1 次 mulx），|u₁| < 1.8·2^−(b+1)（m < 1 一侧 1/(1 + j₁2^−b) 可达 √2，c₁ 又经过舍入；粗略解析界为 (√2 + ½)·2^−(b+1) ≈ 1.91·2^−(b+1)，b = 3…12 精确核对的最大值为 1.38–1.78·2^−(b+1)）。第二级表按 |j| ≤ ⌈1.8·2^b⌉ 定尺寸（依据核对值，b = 4 时恰好够；b 超出 3…12 时重新核对），或在 m < 1 的一半用更细的索引。
2. 第 ℓ 级：j = round(u·2^(bℓ+1))（有符号），c = 1/(1 + j·2^(−bℓ−1)) 舍入成 bℓ + b + 2 bit，u ← (1+u)·c − 1。每级截断到 n+1 limb。若实验 #1 采纳 §3.6 的共享短乘子族，ℓ ≥ 4 时改用 s = 1 + j·2^−bℓ（j = −round(u·2^bℓ)），表存 −log s。
3. 表 LT_ℓ[j] = −log c（n+1 limb），只做加法累计。
4. 尾部：log1p(u_L) = u − u²/2 + u³/3 − …，渐缩，1/k 用定点常数。没有除法，也不用 atanh 形式；mp_real 的 2 limb log1p 调用了 `flint_mpn_tdiv_qr`。
5. 重构：k·ln2 + ΣLT + poly。x 接近 1 时（k = 0 且 j₁ = 0，对 1 的两侧都成立），结果就是多项式本身。但定点（n+1 limb）上的截断是绝对的，|u| < 2^−(64+c_f) 时相对精度就不再满足 64n − c_f（例：n = 4、m = 1 + 2^−150 时 u²/2 = 2^−301 在 2^−320 网格上截断，相对误差约 2^−170，要求约 2^−253）。所以多项式尾部在以 u 的量级为基准的网格上求值（先把 u 左移 lzcnt 位，渐缩规则按 |u| 计），或 |m − 1| < 2^−60 时走缩放的 log1p 内核；截断点写进 `//@` 规格。
6. log1p(x)：对 (1, x) 这一对做同样的约化，(1+x)c − 1 = (c−1) + x·c，第一级是精确的。

**M 段**

- **变体 A**（L 模式 BKM，≥4096 bit）：
  1. 贪心构造 P = Π(1+2^−i) ≤ X，同时精确维护 D = X − P；两者的更新都是在 len(P) 上的移位加；
  2. t = D/(X+P)，除法只需 p − r bit；
  3. 在 t² 上做 atanh 级数，系数用公共奇分母 lcm(1, 3, …, 2N−1) 下的多数位整数；
  4. 最后加 ΣL_i（rowsum）+ 2t·P(t²)。
- **变体 B**（无除法，≤2048 bit）：
  1. 对 x 本身做乘性规范化 x·Π(1 + d_i·2^−i) → 1，全长移位加；
  2. 在 u = x_final − 1 上做 log1p 级数（N ≈ p/r 项，系数 1/k 用 lcm(1..N) 公分母）。
  - 省掉约 3 M 的小尺寸除法，代价是级数项数翻倍。
- 两种变体都与 exp 共用 log(1+2^−i) 行。窗口决策的判据是每个窗口一次的 1 limb 商 D/P（§3.6）。
- **预测**：1024–65536 bit 依次为 350 ns、650 ns、1.56 µs、5.2 µs、17.4 µs、139 µs，即 mp_real 的 0.46 / 0.34 / 0.25 / 0.25 / 0.26 / 0.13 倍 [模型]。

**H–X 段：Newton–Taylor**

1. 种子可以任意取：令 y₀ = Σc_i·L_i + s，其中 s 是 W/8 bit 的短二进制数（对 log m 的 W/8 位近似做 CVP 得到）。于是 exp(−y₀) = Π(有理数)^(−c_i)·exp(−s)，只有 s 走 bit-burst，W/8 以上的切片都不存在。
2. 把 x 折进 N₀（N₀ = x·(1/Den)），δ = N_K − 1 不需要额外的乘法。
3. log m = y₀ + log1p(δ)，|δ| < 2^(−W/8)，用 7 个渐缩项（约 3.5 M）。种子的误差只决定 |δ| 的大小，**不要再算一次**。
4. 代价 k_log ≈ 1.13·k_exp + 1.5。k_at = 13 时：256k 约 2.2 ms，1M 约 12.8 ms，在目标之内 [模型]。
5. 不用 AGM：θ 初始化的 AGM log 在 64k–1M 只能与无表路径打平，比 warm 多素数路径慢 2 倍。等 `RSQRT_GENERAL` 实测 ≤2 M 之后，再对 >2^25 bit 的冷 log 重新评估。

**光滑有理数的对数**（H 段，新思路 [假设]）：原子的素数指数矩阵是幺模的（§3.6），所以任何 P-光滑有理数 k（P ≤ 41，或 k_at = 48 时 ≤223）都有 log k = Σc_i·L_i，c_i 是离线算好的整数。原子库已热时，这只是一遍 k 项 IFMA 点积，O(n)，没有除法。log_base(k) 和 pow(k, y) 中的 log k（例如 10^y、3^y）都能受益。

**派生函数**

- log2、log10：k + log(m)·(1/ln2) 或 ·(1/ln10)，倒数是预存常数；整数部分保持精确，2 和 10 的精确幂特判。
- log1p 极小参数：|δ| ≤ 2^(−p−6) 时直接返回 δ，半径为 δ²/(2(1−|δ|))；2^(−p−6) < |δ| < 2^−60 走上面第 5 步的缩放内核。
- asinh(a) = sign·log1p(a + a²/(1 + √(1+a²)))；大 a 时用 log a + ln2，修正量在 (0, 1/(4a²)] 之内。
- acosh(1+d) = log1p(d + √(d(d+2)))，d 精确；大 x 时用 log x + ln2，误差 ≤1/x²。
- atanh(x) = sign·½·log1p(2|x|/(1−|x|))，d = 1 − |x| 精确。
- 以上都在 L1 内组合，不在 L2 串联。

**球**：log(m ± r)（m > r）的半径 ≤ r/(m−r)；log1p(u ± ε) 传播 ε/(1 + u − ε)，分母取严格下界。

### 4.7 三角族（sin、cos、sincos、tan、sinpi、cospi）

**约化**

- |x| < π/4 不约化；否则一律用 Payne–Hanek 窗口（§3.6）：按 limb 对齐读取时窗口 2n + 1 + ⌈(g+3)/64⌉ 个 limb，中间积输出 n + ⌈(g+3)/64⌉ limb，额外代价 ≈ M(n) + Mh(n)，与 |x| 无关，也没有 Cody–Waite 分支。
- 只保留 q mod 4（或 mod 8）。
- 静态 2/π 表覆盖 E + p + g ≤ 2^17；更大时从常数库取，按见过的最大 E 缓存。过高的输入可以截断到 K ≥ E + P + g bit，截掉的尾部计入误差。

**S 段**

- **n = 1–2**：
  1. 第一级 j = round(t·2^8)，u = t − j/256 精确（j/256 是短二进制数，不需要角度表）。
  2. 第二级 j₂ = round(u·2^17)，|u₂| ≤ 2^−18。
  3. 表存 (S, C) 到 n（或 n+1）limb，第二级存 1 − cos。
  4. 多项式都在 v = u² 上：n = 1 时 sin = u − u³/6、cos = 1 − u²/2（3 次 mulx）；n = 2 时 sin 到 u⁵、cos 到 u⁶（约 8 次渐缩 mulx）。
  5. 两次复数乘：n = 1 共 8 次 mulx，n = 2 共 24–32 次。
  - 估计：n = 1 为 6–11 ns，n = 2 为 20–32 ns。目标 13 / 35 ns；n = 2 约为竞品的 0.6 倍。
- **n = 3–8：短高斯整数旋转**
  - 用短高斯整数 (c̃ + i·s̃) 旋转 (cos u, sin u)。c̃、s̃ 舍入到约 9ℓ + 9 bit，角度 θ̃ = atan2(s̃, c̃) 以 n+1 limb 存表。每级 4 次 n×1，逐级截断。
  - 最后用 rsqrt(Π(c̃² + s̃²)) 统一归一一次：这是对一个短精确整数做 rsqrt，约 3·mh(n)，再加 2·mh(n)。
  - 估计：n = 4 为 230 次 mulx，约 77 ns，目标 90 ns；n = 8 为 819 次 mulx，约 265 ns，目标 340 ns（约 0.83 倍，是 S 段最薄弱的格子）。若生成代码只达到朴素 C 的 2.3 c/mulx（时间乘 1.45）：256 bit 约 112 ns（同 limb 区间竞品的 0.74 倍，超目标 24%），512 bit 约 384 ns（0.93 倍，超目标 13%）；exp/log/atan 的 n = 4/8 目标也全部超出 1–14%（§6.2）。

**M 段**

- 按 atan(2^−i) 做按位约化。
- sin 与 1−cos 的级数在 v = t² 上共享各次幂；第二个输出只多付它自己的边界积和标量项。
- 重构有两种，各自需要不同的约化：
  - **贪心 W/W̄**：用 {0,1} 选择约化 x/2（约 r/2 行）。W = Π(1 + i·2^−i) 用积形式求，再求 |W|²、Re W²、Im W²（2 Sqh + 1 Mh），做一次复数乘（3–4 Mh），两次除以 |W|²（1 次倒数 + 2 Mh）。共约 7 Mh + 2 Sqh + 1 次倒数。
  - **恒增益 CORDIC**：对 x 本身，在每个 i ≤ r 用 σ_i ∈ {±1} 约化（r 行），再用 σ_i·atan(2^−i) 旋转 (cos t, sin t)。共 2r 次全长移位加，最后两个分量各乘一次缓存好的 1/K，K = Π√(1 + 4^−i)，即 2 Mh，没有除法。
  - 模型（`mid_model.py` base 变体，CORDIC 按 r 行约化计费）：8192/16384 bit 选 CORDIC（约 11%），4096/65536 选贪心（2% / 10%），1024/2048 两者相差约 4.6% / 2.3%（CORDIC 略快），由实验决定。约化方式不同，所以这个选择是整条路线的选择，不是同一次约化之后再挑。
- **只算 sin、cos 用 √ 求**：只有在第二个级数的边界积超过一次带种子的 sqrt（约 1–1.5 M）时才划算，即 ≥16 kbit 且 N ≥ 50。
- **预测**（1024–65536 bit，base 变体）：0.70、1.21、2.97、10.1、32.8、250 µs，即 mp_real 的 0.54 / 0.35 / 0.29 / 0.29 / 0.30 / 0.27 倍。1024 bit 的基础模型已与目标（705 ns）持平，保守模型为 855 ns（0.67 倍），需要 M1 生成内核（省 20–30%）；2048 bit 的保守模型 1.45 µs 也高于目标 [模型]。

**H–X 段**：高斯 bit-burst（§3.7）。

- 预测（k_at = 32 个高斯原子）：256k 为 2.23 ms，1M 为 13.2 ms；目标 2.55 / 16.8 ms。
- 没有原子库时为最佳竞品的 0.56–0.68 倍（256k–1M），达不到目标，所以 H 段的三角必须建原子库。

**tan**

- 短旋转是尺度不变的：tan = S/C，可以跳过归一直接除一次，代价 ≈ sin_cos − 3·mh(n) + div。
- 也可以用 mp_real 的半角/高斯积路线，它不需要除法 [实测，`warm2.csv` mp_real.fix tan 与 sin_cos 行：原始 tan 是原始 sin_cos 的 0.91–1.03 倍]。这条路线达标后，目标收紧到 1.05 SC。
- H 段：tan = Im N / Re N，Den 约掉。

**sinpi/cospi**：在二进制有理数上精确约化 2x mod 4；整数和半整数直接给出精确值，不经过 π；只有残差乘 π。

**零点附近**

- 微小 r：sin r ≈ r，误差 ≤|r|³/6。
- 1 − cos 用 s²/(1+c)，绝不直接算 1 − c。
- 内核给的是绝对精度：sin 在 kπ 附近的相对精度会损失，球层如实反映在半径里（与 Arb 相同）；L3 需要额外的残差位。

**球**：sin/cos 的半径 ≤ min(r, 2)；tan 的半径 ≈ r/cos²（取最坏点），球包含极点时结果为不定。

**优化点**：第一级残差精确；短旋转；FP64 索引链；sin 与 1−cos 共享幂；恒增益 CORDIC；只算 sin 再开方；高斯切片共享实分母；无除法的 tan；Payne–Hanek 中间积；静态 2/π 表。

### 4.8 反三角（atan、atan2、asin、acos）

**S 段：旋转法**

1. 从 z = (a, b) 出发：atan 取 (1, x)，atan2 直接用给定的 (a, b)。
2. 八分区交换：b > a 时改算 π/2 − atan2(a, b)，不做除法。
3. 第 ℓ 级：c_ℓ = round((b/a)·2^(bℓ))·2^(−bℓ)。比值 r ← (r − c)/(1 + r·c) 用 FP64 跟踪，每级约 10 c，走 FP 端口；整数端口同时做旋转 (a + b·c, b − a·c)，即 2 次 n×1，逐级截断。
4. 结尾：atan2 = Σatan(c_ℓ)（查表）+ atan(b_L/a_L)。最后的比值 < 2^(−bL)，只需要一次 n limb 除法加一段短奇级数。

| n | 配置 | mulx | 估计 | 目标 | 最佳竞品 |
|---|---|---|---|---|---|
| 1 | L=1×8，7 次 | 15 | 约 10 ns | 12 ns | 20 ns |
| 2 | L=2×8 | 45 | 约 24 ns | 28 ns | 37 ns |
| 4 | L=4×7 | 137 | 约 47 ns | 60 ns | 106 ns |
| 8 | L=5×6 | 463 | 约 151 ns | 200 ns | 372 ns |

**asin/acos**：asin x = atan2(x, √((1−x)(1+x)))，acos x = atan2(√((1−x)(1+x)), x)。1 ± x 先由精确输入形成；旋转直接使用这一对数，不需要比值除法。acos 在 1 附近绝不能算成 π/2 − asin。

**M 段**

- 按 atan(2^−i) 对 (1, x) 做按位旋转，每个用到的下标做两次全长移位加（两个分量都是稠密的）；判据是每个窗口一次的 1 limb 商 v/u。
- 然后 t = v/u（除法只需 p − r bit），在 t² 上做奇 atan 级数，最后加 Σatan(2^−i) + t·P(t²)。
- 备选：CORDIC 向量模式。总是旋转，方向由 v 的符号决定；不需要对精确值做决策，对冗余表示也鲁棒，但旋转次数是 r 而不是 r/2。
- **预测**（1024–65536 bit）：0.50、0.82、1.91、6.4、21.0、167 µs，即 mp_real 的 0.51 / 0.29 / 0.22 / 0.26 / 0.24 / 0.14 倍 [模型]。1024 bit 的目标（489 ns）略低于基础模型，依赖 M1 内核。

**H–X 段：基于 sincos 的 Newton–Taylor**

1. 种子 y₀ = Σc_i·α_i + s，α_i 是高斯原子角，s 是 W/8 bit 的短二进制数（做法同 §4.6）。
2. (N_re, N_im) = sincos(y₀) 的累加器。
3. δ = (x·N_re − N_im)/(N_re + x·N_im)：Den 约掉；一次除法，精度 W − W/8，分子很小。
4. atan x = y₀ + atan δ（4 个奇数项）。
- 代价 k_atan ≈ 1.13·k_sincos + 4。k_at = 32 时：256k 约 2.6 ms，1M 约 15.7 ms（目标 2.91 / 18 ms）[模型]。

复 AGM 求 atan：每次迭代约 15 M，1M limb 时约需 52 次迭代，永远比不过 bit-burst，只作研究对照。

**球**：atan 的半径 ≤ r/(1 + max(0, |m|−r)²)（≤ r）；asin 的半径 ≤ r/√(1 − (|m|+r)²)。球伸出 ±1 时结果为不定（同 Arb）。

**陷阱**

- atan2 内部的比值下溢不等于结果下溢。
- 只保留小残差会丢掉象限信息。
- atan(2^k·x) = 2^k·atan(x) 这个"齐次性"是错的。

### 4.9 pow 与 powi

| 情形 | 算法 |
|---|---|
| y 为整数 | 二进制幂（≤2·log2\|y\| 次乘法），宽指数跟踪；误差 \|log(x̂^N/x^N)\| < 36·N·u，工作精度 q = p + bitlen(N) + 16（取自 astra 的证明） |
| y = ±½ | sqrt / rsqrt |
| y = k/2^m（k、m 小） | 先幂再做 m 次 sqrt |
| 一般 y，x > 0 | exp(y·log x)。t = y·log x 需要与 exp 的相对目标相当的**绝对**误差，所以 log x 算到 n + ⌈(log2\|y·log x\| + 4)/64⌉ limb（通常是 n+1）；x 接近 1 时用 log1p(x−1)；x 是光滑有理数且原子库已热时，用 §4.6 的光滑有理数对数 |
| x^y − 1，x 接近 1 | expm1(y·log1p(x−1)) |
| x < 0 | y 必须是整数（球 y 只能包含一个整数），按奇偶性定符号 |

**球**：|Δt| ≤ (|y| + r_y)·r_x/(|x| − r_x) + (|log x| + r_x/(|x| − r_x))·r_y；半径 = |x^y|_up·expm1(|Δt|)，在 xd 中向上舍入。

H 段的 log 走 Newton–Taylor，与 exp 共享计划和常数。目标 ≤ E(n) + L(n+1) + 2M。

### 4.10 AGM 与完全椭圆积分

**AGM(a, b)**

- **迭代次数**：以 agm(1, x)、x ∈ (1, 2) 为例。z₀ = (x−1)/(x+1)，h_{k+1} = 2h_k + 2；2h ≥ p/m 时停止，m 是收尾阶数：≤1024 limb 用 8，更大用 12。
  - x ≈ 1.5（h₀ ≈ 2.3）时，1024/2048/4096/8192/16384/65536 bit 依次需要 J = 4/5/6/7/8/10 次迭代；x → 2 时各多 1 次。
- **全程使用公共全精度。** 前向 AGM 不自纠正（共模误差的特征值是 1），所以绝不能按 p/4 → p/2 → p 的阶梯迭代。可变精度只能用在 sqrt/乘法内部和收尾项上。
- **每次迭代**：Mh(ab) + sqrt + 3 遍线性运算。sqrt 可以用上一次迭代的结果做种子，因为 b_{n+1}/b_n ≈ 1 + O(t)；收益小 [假设]。
- **收尾**：
  - M = A·(1 − Σc_j·x^j)，A = (a_r + b_r)/2，x = ((a_r − b_r)/(a_r + b_r))²。
  - c_j 是 < 2^45 的二进制有理数，且 Σc_j = 1，所以尾项 ≤ x^m。
  - 各次幂用渐缩平方（约 4 次 Sqh），系数点积几乎免费，最后一次 Mh。第 j 项只需 p − j·h bit。
- **有理化间隙** [假设]：Δ = A − B = d²/(A+B)，这样就不必相减两个接近的已舍入平方根；ab = A² − d²，用一次全平方加一次 d 的短平方代替一次全乘。后期 b' = A·√(1−δ) 用一段短级数。按收尾阶数 8 计，只有最后 1–2 次迭代适用，约省 5–10%。
- **误差**：由齐次性和单调性，公共相对扰动的贡献 ≤ 2kη·M，对数包络每步 ≤3u。误差界由元数据解析算出，不需要逐 limb 的区间运算（取自 astra 的 AGM 误差模型）。
- **球**：两个输入同时乘以 (1 ± ρ)，M 也乘以 (1 ± ρ)，所以相对半径 = max(r_a/a, r_b/b) + 求值误差。便宜且紧。
- **预测**：
  - S 段受延迟限制：30–50 / 70–110 / 180–260 / 400–600 ns（64/128/256/512 bit）。
  - M 段：0.83、1.68、3.77、11.7、41.9、321 µs（1024–65536 bit），即 16–38 M；竞品为 56–118 M。
  - H 段：k ≈ 12–14 次迭代 × 约 3.3 M（Mh + 一般 sqrt），即 44–50 M；目标 ≤57 M。

**K(m) 与 E(m)**

- K(m) = π/(2·AGM(1, √(1−m)))，直接接受补参数 c = 1 − m。
- E 的公式：
  - E = K·C，其中 C = (1+c)/2 − Σ_{j<r} 2^j·d_j² − 2^r·D_*，d_j = (a_j − b_j)/2（a₀ = 1，b₀ = √c；取 a_j − b_j 本身会让减去的和错 4 倍）；
  - D_* = 2A²x[1 + 2(1−x)P'/P]，A = (a_r + b_r)/2，x = ((a_r − b_r)/(a_r + b_r))²，P 是收尾多项式（1/₂F₁(½,½;1;x)）；
  - 尾项 ≤ 8(q+1)A²x^q，收尾阶数 q ∈ {2, 4, 8, 16}（用 q 而不是 n，以免与 limb 数混淆）。已用 mpmath 80 位核对：m ∈ {0.3, 0.5, 0.9, 0.999}、r = 0…3 时与 ellipe(m) 相差 ≤2·10^−81，实际尾项比这个界小 10–200 倍 [模型]。
- 只看 K 的停止判据，不能保证 E 的精度。
- 特殊情形：m = 1 时 K = ∞、E = 1；m < 0 时用 t = m/(m−1) 变换；c → 0 附近用 E = c·K + c(1−c)/3·R_D(0, 1, c)，它没有相消，作为后备和对照。
- 代价：K 约为 AGM + sqrt + div + 一次常数读；E 另加若干短平方。

**AGM 求 log**（Sasaki–Kanada θ 初始化）：−log a = (π/4)/M(4r²S₂², T₃²) − e·ln2，第一步不需要开方，比经典形式约少 9 次迭代。它只作为 >2^25 bit 冷 log 的研究选项（§4.6）。

### 4.11 常数

- 接口：`get(id, n)` 返回认证过的下取整前缀，半径恰为 1 ulp，中点与缓存历史无关。
- 列表：π、ln2、ln10、log2(10)、1/ln2、1/ln10、e、2/π、γ、Catalan、ζ(3)、√2；H 段还有多素数原子和高斯原子角（不进静态表）。π/2、π/4、1/π 由指数平移或前缀派生。
- 实现见 §3.8。

### 4.12 转换与输入输出

- 从 int64、double、`sbn::integer`、二进制有理数转换都是精确的，存储时去尾零。
- 转 double：对中点舍入。转整数：floor/ceil/round，并检查球是否跨过整数边界。
- 十进制输出：用 L0 radix 的 ENCLOSED 模式，只输出区间内确定的数字，这天然就是球的打印方式。H 段的输出代价 ≤ c·M(n)·log n。
- 解析：用 radix 解析成二进制有理数加半径。
- ≤8 limb 的小十进制原语已经有了，不需要运行时对象。

### 4.14 批量接口（纵向 SIMD）

- **布局**：`block8<N>`，SoA，8 道，每道一个独立的求值；d = ⌈(64n + g)/52⌉ 个数位。截断的 d×d 高半积约需 d(d+1)/2 + d 个数位对，每对 2 条 IFMA，外加约 3d 次向量操作做惰性规范化。

| bit | d | IFMA，每道每积（c） | 标量每积（c） | 倍数 |
|---|---|---|---|---|
| 64 | 2 | 约 0.7 | 约 3 | 4× |
| 128 | 3 | 约 1.25 | 约 6 | 4.8× |
| 256 | 5 | 约 2.75 | 约 18 | 6.5× |
| 512 | 10 | 约 8.75 | 约 55 | 6.3× |

- **查表不用 gather**：每级 4 bit，16 项的表放在两个 zmm 里，用 `vpermi2q` 查；Tang 短值级就是一次 d×1 的 IFMA 乘法。
- **例外道**：特殊值、宽球、超出快速范围的道用掩码剔除，压缩成下标列表，之后交给标量路径。
- **与标量共享的部分**：批量内核与标量内核共享生成器和系数数据，但不共享实例化后的内核本身：标量用 8 bit 直接索引和 u64 limb 表，批量用 4 bit `vpermi2q` 级和 u52 数位。分支必须对所有道一致，办法是按约化类别给参数分桶。
- **半径**：每块可以选择共享一个半径指数（van der Hoeven–Lecerf 的"共享误差界"向量），点积同理。对生成的 Horner/直线程序，可以在静态误差界下求值。
- **目标**：见 §2.5。预测的每元素吞吐：exp 为 0.8–1.2 / 2.5–3.5 / 6–9 / 20–30 ns（64/128/256/512 bit），是当前单次调用前沿的 1/10 到 1/48。
- **用途**：球的向量和矩阵（点积、128–512 bit 定点矩阵乘）、特殊函数的内循环、对多个盒子做 ODE/Newton、表生成。库内部也用：BurstTree 的底层、多素数积树的叶子。单次标量调用永远不划算。

### 4.15 L3（正确舍入定精度）展望

**沿用 L1 的部分**

- 内核和生成器证明的先验误差界原样使用。L3 = 内核 → Ziv 测试 → 完成（或重试）。
- 目标精度 p < 64n、误差 ≤ ε ulp 时，若 round_p(M − ε) == round_p(M + ε) 则可以正确舍入；这个测试只是低 limb 上的 3–4 次整数运算。失败概率约 2ε·2^(p−64n)。选满足 64n − p − log2 ε ≥ 10 的内核，失败率可以低于 2^−9。
- 重试阶梯：紧变体 → n+1 → 一般段内核。p > 64 时没有最坏情形表，所以阶梯不能设上限。
- 例：binary128（113 bit）的 exp 用 n = 2 的紧内核（128 bit 时 ≤1 ulp，留 15 个守护位，失败率约 2^−14），估计约 15 ns；MPFR 在 108–117 bit 要 585 ns。

**必须不同的部分**

1. Ziv 之前先做精确性检测，否则遇到精确情形会死循环。exp/log/sin/cos/atan 只在平凡点上精确（Lindemann–Weierstrass）；sqrt/div/pow/rootn/cbrt 需要"余数为零"或"精确幂"的测试。
2. IEEE 语义：±0、Inf、NaN、标志位，以及目标格式的次正规数和上下溢阈值。
3. 有向舍入：每种模式的边界测试不同。
4. 误差界的紧度更重要：界宽 16 倍就多费 4 bit，重试也多 16 倍。紧变体是 L3 的主力，到 L3 立项时再生成。
5. 不需要球的机制。
6. binary64/32 的前沿是 CORE-MATH 的 double-double 快路径（MIT 许可），不要用 64 bit limb 内核去争。

发布方式按 decimal 的先例，用 `inline_export: "fp_cr"`。

### 4.16 谓词与区间运算

Arb 式用户在 Newton 迭代、二分、根隔离的内循环里大量调用这些操作，测试和 fcheck 从 P1 起也要用到，所以与基本运算一起在 P1 交付。

| 类 | 操作 |
|---|---|
| 谓词 | contains、overlaps、确定的 lt/le/eq、is_zero/positive/finite、contains_zero、contains_int、is_exact、rel_accuracy_bits |
| 区间运算 | union、intersection、add_error、get_mid/get_rad、lower/upper bound、trim、nonnegative_part、sqrtpos |
| 平凡运算 | abs、neg、sgn、min/max、mul_2exp |

实现：偏置指数比较，加首 limb 比较；端点用半径的上界；只有持平时才逐 limb 比较；不分配内存。目标见 §2.2。

## 6. 风险与未决问题

### 6.1 竞品在快速变化

mp_real 2026-09-26 才合入，10-05 又加了多线程。我们钉在 657a283；每月对上游 HEAD 复测一次锚点（只测锚点），据此更新 `targets.py` 和本文。

### 6.2 大部分数字是模型

- S 段只有 n ≤ 2 是实测。
- M 段的线性遍是实测，其余是模型（在 512–16384 bit 的校准误差为 +1% 至 +18%；64k 是外推）。
- H 段是校准过的模型（±15%）。
- 最大的不确定性是生成代码的效率：如果只达到朴素 C 的 2.3 c/mulx，S 段 n ≥ 3 的各项要乘 1.45。此时 256 bit sin_cos 约 112 ns（同 limb 区间竞品的 0.74 倍，超目标 24%），512 bit 约 384 ns（0.93 倍，超目标 13%）；exp/log/atan 在 n = 4/8 的目标也全部超出 1–14%。

### 6.3 最紧的格子

| 段 | 格子 |
|---|---|
| S | sin_cos 在 n = 8（0.83×）和 n = 2（0.6×）；atan 在 n = 2（0.76×）；n ≥ 3 的全部初等函数依赖生成代码达到约 1.6 c/mulx（§6.2） |
| 513–1023 bit | 所有由 S 段 n = 8 插值的目标（exp、log、atan、sin_cos、div、sqrt、rsqrt、cbrt、agm）都低于 M 段基础模型（576 bit 的 exp、div 为 0.67×，832 bit 的 div 为 0.56×）；依赖 S 段定长内核延伸到 n ≤ 16（实验 #23） |
| M1 | 1024 bit 的 exp、log、atan、sin_cos、div、sqrt、rsqrt，以及 2048 bit 的 log、sin_cos、sqrt、rsqrt 低于保守或基础模型，依赖 M1 整函数内核（实验 #5） |
| M3 | 64k bit：rsqrt 22 µs 低于基础模型 25 µs（依赖三阶迭代与频谱共享）；exp、log、atan、AGM 取 1.1× 保守模型，而模型本身是外推 |
| H | 256k–1M 依赖原子库和 BurstTree 的低开销执行器：执行器若保持现在每次积约 300 ns 的开销，256k 附近的格子会退到 0.5× 左右 |
| 加法 | 64–1023 limb ≤1.15×、≥1024 limb ≤1.05× `add_n`（实验 #17）；92k–96k bit 约 0.96× 最佳竞品，`add_n` 是上限 |

### 6.4 原子库与可复现性

- H 段在原子库建成之前要多付 1.5–1.9 倍，建库本身相当于 6–23 次 warm exp，所以用租雪橇规则控制（§1.7）。
- H 段的结果依赖原子库状态和线程数：测试只比较包含性，回归测试用确定性模式。

### 6.5 L0 依赖项（完整清单）

| 类 | 依赖项 |
|---|---|
| 内核 | 生成的定长内核（并修复 `sbn3_mul_basecase` 在 n = 7 的断崖）；带误差界的 IFMA mulhigh；u52 平方；u52 无 Frame 入口；k 项点积；u52 MAC2（16–256 limb）；纵向 8 道 IFMA 内核（vmul/vmulhigh/vaddmul_1、16 项叶子批）；K 链 `divrem_1` |
| 乘法基础设施 | pq16 按尺寸类的形状缓存（放在 L0，BurstTree 上层也要用） |
| Newton | `RSQRT_GENERAL`；`MUL_RSQRT_GENERAL`；预备除数 |
| 常数与级数 | π/e 的近似入口；Frame 形式的常数生产者（或 Frame 版 PSR）；闭式停止下标；`ProductDecisionLog` 重放；`Merge::multiply` 小节点快路径；BurstTree（`src/series/burst*`）；γ 的矩阵合并配方；幺模的 Størmer 原子目录 |

这些改动有几项落在已经与 y-cruncher 对标认证过的路径上，必须用 π/e 锚点做 A/B；而且这些文件目前正被其他代理编辑（单一共享工作树），动手之前先协调（章程 §10）。

另外，本文引用的部分 L0 符号与行号（`matrix_execute`、`program_sum_execute`、`normalized_newton_*`、`finite_frame_*`、u52 middle 的改动、`src/series/arithmetic.cpp:870-875`）以 2026-10-08 共享工作树中**尚未提交**的改动为准，HEAD（fb1d517）里还没有。float-rewrite 分支只能从包含这些改动的提交分出（章程 §10）。

### 6.6 精度语义

类 Arb、不加守护 limb，这与 MPFR 用户的直觉不同。要在文档和 API 中写清楚，并用 acc_bits 门槛保证交付精度。需要精确语义的用户用 L3。

### 6.7 代码体积

S 段的内核多、表也多。.text 预算 512 KB，.rodata 预算 768 KB，在每个里程碑检查。

### 6.8 缺少 2^20 bit 以上的竞品数据

X 段的目标只能用 M_sbn 倍数表示（M_sbn 已测到 2^24 bit）；mp_real/arb 在 4M 和 16M bit 的锚点仍待补测，作为对照。

**不得重犯的做法**：

- 在内循环里调用公开契约原语；
- 每次调用都查询、规划、准备；
- 每次调用重算常数；
- 通用的守护位膨胀（p+128、2p+256、4p+640）；
- 五种并不真正正确舍入的舍入模式；
- "点值 + 每次运算一张误差回执"；

- 实现了却从不调度的代码；
- 先写文档、后做性能；
